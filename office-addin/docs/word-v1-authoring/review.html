What makes this possible in v1?

  1. Read the body in bounded groups. The current excerpt cannot represent a long document. Track complete source coverage and model budgets.
  2. Separate source from output shape. Stable references identify the old content; typed blocks describe the new order and structure.
  3. Review one coherent result. A moved section and its replacement are not independently skippable edits.
  4. Keep direct writing as the first channel. Attributed document comparison and tracked-suggestion workflows remain separate.

What must be proven in Word?

  • Preservation: real styles and lists, plus supported links and objects. Unsupported content must be protected, not flattened.
  • Freshness: reject stale plans before writing; measure the remaining coauthor race.
  • Failures: Word execution is not promised atomic. Report partial writes and prevent blind retry.
  • Recovery: Revert must not erase edits made after application.
  • Hosts and scale: certify the supported Mac, Windows and web combinations using long fixtures.

Keep the useful infrastructure. Change the authoring contract.

Existing paragraph review, consent, client tools and compact results remain useful. Add a read-only body tool and a distinct structural action with its own permission.
