## Summary

Bumps the pinned Git revision of the `genai` crate (a fork maintained at
`https://github.com/EratoLab/rust-genai.git`, version
`0.6.0-beta.19-WIP`) in `backend/erato/Cargo.toml` and `backend/Cargo.lock`
from commit `eeb52ab1961d` to `0edafffd027d`. This is the LLM/GenAI client
