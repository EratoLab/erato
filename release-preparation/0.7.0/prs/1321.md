## Summary

Fixes an intermittently flaky e2e test
(`mock-flows.many-models.spec.ts`, "Draft message and selected files are
preserved per chat when switching chats") by replacing a loose
`page.getByText(/sample.*compressed.*pdf/i)` locator with a precise
`pdfAttachmentChip` locator scoped to the attachment-preview button's
accessible name. The loose text locator could match two elements at
once — the attachment chip itself and, per the PR's own failure log, the
composer's separate "context budget" notice that also lists the
filename — causing Playwright's strict-mode violation and an
intermittent CI failure. All 5 call sites in the spec file are updated to
the new locator.

## Compatibility and configuration

None. Test-only change (e2e spec file), no production code touched.
