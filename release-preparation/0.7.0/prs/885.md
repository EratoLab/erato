# PR #885: Update k3d to v5.9.0

- PR: https://github.com/EratoLab/erato/pull/885
- Status: pending
- Category: Chores & Developer experience
- Theme: None

## Summary

Pins the `k3d` (local Kubernetes-in-Docker) CLI version used in CI/local
dev to `v5.9.0` (new `K3D_VERSION` env var in
`.github/workflows/docker-build.yml`; the install step now uses that
pinned tag with `--fail --silent --show-error --location` curl flags
instead of installing whatever the `main` branch's install script
resolves to). `infrastructure/k3d/cluster-config.yaml` bumps its
`apiVersion` from `k3d.io/v1alpha4` to `k3d.io/v1alpha5` (required by the
newer k3d CLI) and the underlying Kubernetes distribution image from
`rancher/k3s:v1.34.1-k3s1` to `rancher/k3s:v1.36.2-k3s1`.

## Compatibility and configuration

No production configuration keys or migrations; this only affects the
local/CI development Kubernetes cluster setup
(`infrastructure/k3d/`), not any deployed environment. Developers running
the local k3d-based dev cluster get a newer k3d CLI and a newer k3s
(Kubernetes) version.
