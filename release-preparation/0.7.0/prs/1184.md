# PR #1184: Extend sidecar RPC with generalized source listing and folders

- PR: https://github.com/EratoLab/erato/pull/1184
- Status: pending (diff reviewed)
- Category: Features and enhancements
- Theme: Desktop Sidecar for local sources

## Summary

Pure desktop-sidecar protocol-specification addition (no backend/frontend
application code touched). Generalizes the mailbox-specific listing from
#869 into a source-kind-agnostic model: a new `SourceDescriptor` shape
(`sourceId`, `sourceKind`, `sourceKey`, an opaque `locator` object, `enabled`,
plus discovery/scan-state fields: `discoveryCursor`, `completedScanId`,
`lastSuccessAt`, `lastErrorCode`) represents any indexable local data
source — mailboxes, but per the new `sources.get_folder_hierarchy.v1`
method, also filesystem folder trees. New methods: `sources.list.v1`
(returns all `SourceDescriptor`s) and
`sources.get_folder_hierarchy.v1` (returns a `SourceFolderHierarchyNode`
tree: `nodeId`/`parentNodeId`/`name`/`pathName`, plus
direct/total leaf and child counts, so a client can browse folder
structure without fetching every leaf item). `search.query.v1`'s params
schema also gained a 1-line addition, presumably to filter search by
source.

## Compatibility and configuration

No backend/frontend configuration keys or migrations — protocol
specification only; no Erato application code consumes these new methods
in this diff. No production impact until a real sidecar implementation and
corresponding client integration land.
