# PR #1299: Render existing file references as native Teams citations

- PR: https://github.com/EratoLab/erato/pull/1299
- Status: pending (diff reviewed)
- Category: Features and enhancements
- Theme: Teams

## Summary

Adds the ability to render file references from chat messages as native Microsoft Teams citation cards. When the Teams bot sends a message that references uploaded, generated, or attached files, those references are now converted to Teams-compatible citation attachments that users can click to view or download the file directly from the Teams conversation.

**New `citations` module** (413 lines + 162 lines tests): Converts internal file references (stored as `erato-file://` or file-id URIs in the message content) to Teams message attachment citations. The module:

1. Maintains a mapping from internal file IDs to Teams attachment metadata (download URL, file name, MIME type, size).
2. Generates the correct Teams citation card JSON structure (`ContentType` + `AbstractAttachment`).
3. Handles multiple file types: images (rendered inline), documents (rendered as file cards), and generated files.
4. Deduplicates citations when the same file is referenced multiple times.

**Integration.** The `handler.rs` and `streaming.rs` modules call the citations module during final answer rendering. The `host.rs` module provides the file metadata lookup context. The `streaming/tests.rs` module is extended with citation rendering test cases (125 lines).

**Integration tests.** A new `revisions.rs` integration test module (64 lines) validates the citation rendering against the Teams API message format.

## Compatibility and configuration

No config changes. Citations appear automatically for file references in Teams bot messages.
