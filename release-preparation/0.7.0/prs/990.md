## Summary

Extends the pin/unpin chat action (added to the sidebar chat history list
in #947) to two additional surfaces where past chats are listed:
- `AssistantWelcomeScreen.tsx`'s "past conversations" list — each chat
  card gains a `DropdownMenu` with a Pin/Unpin item, disabled once the
  pinned-chats limit is reached (same "Pin limit reached" label and
  `pinnedChatsCount >= pinnedChatsLimit` logic as #947), or when
  `!chat.canEdit`.
- The search results page (`SearchPage.tsx`, 51-line diff) — presumably
  the same pin action added to each search result row.

Both reuse the existing `pinnedChatsCount`/`pinnedChatsLimit` props
pattern and the `PinIcon`/`PinSlashIcon` icons introduced in #947, applied
consistently to these two additional locations. `ChatEmptyState.tsx` (6
lines), `AssistantsPageStructure.tsx`/`SearchPageStructure.tsx` (41-line
diffs each, likely prop-threading to pass pin handlers/limits down), and
`AssistantChatSpacePage.tsx` (33-line diff, wiring the pin handler into
this specific page) round out the change.

## Compatibility and configuration

None. Purely a frontend UI consistency change — no configuration keys, API
