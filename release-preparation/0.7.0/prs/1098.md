# PR #1098: Fix edit action and other state differences in pinned chats

- PR: https://github.com/EratoLab/erato/pull/1098
- Status: pending (diff reviewed)
- Category: Bug fixes
- Theme: None

## Summary

Fixes several places where a **pinned** chat's state was missing or
incorrect because it is excluded from the regular chat-history listing
(per the new code comment: "Pinned chats are excluded from the regular
history listing"). Various lookups only searched the regular `chats`
list, not the separate `pinnedChats` list, so for a currently-pinned chat
they silently found nothing and fell back to a default/empty value:
- `Chat.tsx`'s `canEditForCurrentChat` — determines whether the "Edit"
  action is available for the current chat's messages; previously always
  fell back to `false` for a pinned chat that wasn't also present in the
  regular listing, incorrectly disabling editing.
- `currentChatLastSelectedFacets` — the last-selected facets for the
  current chat, same gap.
- `useModelHistory`'s `currentChatLastModel` — the historically-used
  model for the current chat, used to show which model was last active.
- `useChatHistory`'s `navigateToChat` (assistant-aware URL construction)
  and its generation-status seeding effect (`seedGenerationStatusFromListing`)
  — both now also check `pinnedChats`.

All fixes follow the same pattern: check `pinnedChats`/`pinnedChatHistory`
first, falling back to the regular `chats`/`chatHistory` list, so a pinned
chat's state is found regardless of which list it currently lives in.

## Compatibility and configuration

None. Purely frontend bug fixes; no configuration, API, or migration
changes. Affects only chats a user has pinned (feature from earlier this
cycle, #947/#990).
