# PR #859: Fix sidebar dropping an unrelated chat when archiving

- PR: https://github.com/EratoLab/erato/pull/859
- Status: pending
- Category: Bug fixes
- Theme: Chat and add-in fixes

## Summary

Archiving a chat could make an unrelated chat vanish from the history sidebar until a hard reload. archiveChat invalidated the infinite recent-chats query, which refetched every loaded page. Since the archive shrinks the server-side result set by one, every page boundary past the archived row shifted, and the offset-based refetch silently skipped the chat that straddled a boundary.
