# PR #1313: Fix Teams chat upload blocking when unrestricted upload is configured

- PR: https://github.com/EratoLab/erato/pull/1313
- Status: pending (diff reviewed)
- Category: Bug fixes
- Theme: None

## Summary

Fixes an issue where the Teams add-in's chat upload widget would block file attachments based on a warning about unsupported text-file processing, even when the deployment had configured unrestricted file upload (`upload_allowed_if_supports = ["any"]`).

**Problem.** The `TeamsChatAddMenuExtraContent` component showed a warning banner explaining that certain file types cannot be processed (text extraction not available), and this warning prevented those file types from being added to the chat context. The check did not account for the deployment's upload policy — if the deployment allowed "any" file type (as opaque blobs without processing), the warning should have been suppressed.

**Fix.** The component now checks the deployment's upload policy before showing the file-type warning. If `upload_allowed_if_supports` includes "any" (or the file type's operation is covered by the policy), the warning is suppressed and the file can be attached. The test coverage is substantially expanded (131 lines added) to cover the various policy/config combinations.

## Compatibility and configuration

No config changes. The fix corrects the interaction between upload policy and the Teams upload widget.
