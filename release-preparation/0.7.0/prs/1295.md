# PR #1295: Pad Word review rows and compile Word's closing paragraph after a final table

- PR: https://github.com/EratoLab/erato/pull/1295
- Status: pending (diff reviewed)
- Category: Bug fixes
- Theme: Word add-in

## Summary

Two fixes for the Word document compilation pipeline:

**Row padding.** `WordPlanChangeRow.tsx` and `wordReview.css` are updated to add proper spacing around review change rows, preventing a cramped appearance when multiple changes are displayed in the same review card. An icon entry is added for visual row indication.

**Closing paragraph after a final table.** When a Word document ends with a table, the story compiler (`wordStories.ts`) previously failed to emit the closing paragraph tag after the table, producing malformed XML that Word would reject on open. The fix ensures the compiler always closes the paragraph container after the final block, even when that block is a table. The `wordDocumentXml.ts` utility is updated to handle this case, and the OOXML host mock (`ooxmlHost.ts`) is extended to support testing full-document compilation. A new test module (`wordApplyFullDocumentPlan.test.ts`, 101 lines) validates the complete apply pipeline for documents ending with tables.
