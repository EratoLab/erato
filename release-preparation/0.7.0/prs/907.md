# PR #907: On "my submission" assistant hub page, order by most recent

- PR: https://github.com/EratoLab/erato/pull/907
- Status: pending (diff reviewed)
- Category: Bug fixes
- Theme: Assistant Hub and assistant sharing

## Summary

Changes the sort order of assistant groups on the "My Assistant Hub
submissions" page (`groupVersionsByAssistant` in
`frontend/src/pages/AssistantHubMyPage.tsx`). Previously groups were
sorted purely alphabetically by assistant name
(`left.name.localeCompare(right.name)`). Now each group is sorted by its
most recent version's `submitted_at` timestamp descending (most recently
submitted first), falling back to alphabetical name order only as a
tie-breaker when two groups' latest submission timestamps are identical.

## Compatibility and configuration

None. Purely a frontend sort-order/UX change; no configuration keys, API
changes, or migrations. The function was also exported (`export const
groupVersionsByAssistant`) so it can presumably be unit-tested directly or
reused elsewhere.
