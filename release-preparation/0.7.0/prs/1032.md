# PR #1032: Add-in: skip the oauth2-proxy session warm for custom-audience tokens

- PR: https://github.com/EratoLab/erato/pull/1032
- Status: pending
- Category: Features and enhancements
- Theme: Product experience

## Summary

GraphTokenProvider.acquireToken opportunistically re-redeems the oauth2-proxy session with whatever bootstrap it just acquired. For Graph scopes that is fine — but when a caller acquires a token for a custom API resource scope (a non-Graph audience), a stale session (20-minute window) gets re-redeemed with an access token the proxy cannot use.
