# PR #1041: Add model switching indicator

## Summary

Shows a small marker in the chat transcript when the user switches which
chat model/provider is answering mid-conversation. New
`frontend/src/utils/chat/modelSwitches.ts`
(`getModelSwitches`) walks the message list in order, tracking each user
message's associated model (from the following assistant message's
`chatProviderId`, recorded against that assistant reply's
`previous_message_id`), and records a switch whenever a user message's
model differs from the previous one — producing a map from message ID to
`{ fromModel, toModel }` (using display names when available, falling
back to the raw provider ID). A new `ModelSwitchMarker.tsx` component
renders this inline in the message list
(`MessageItem.tsx`/`MessageList.tsx`/`StandardMessageList.tsx`/`VirtualizedMessageList.tsx`
all touched to thread this through), presumably as a small "Switched from
X to Y" label before the affected message.

## Compatibility and configuration

None. Purely a frontend, presentation-only feature computed from existing
message metadata (`chatProviderId`, already persisted per assistant
message) — no configuration keys, API changes, or migrations. Always
active, not gated by a feature flag.
