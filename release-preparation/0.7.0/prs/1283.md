## Summary

Adds a guided, tested PowerShell setup script (`Test-EratoTeamsSetup.ps1`) for configuring Teams bot SSO, along with supporting infrastructure and translations. Administrators can now run a single PowerShell script (deployable via Cloud Shell or Azure CLI) that walks through the entire Teams app registration, bot configuration, and SSO setup process.

**New files:**
- `office-addin/scripts/teams-bot/Test-EratoTeamsSetup.ps1` (202 lines): Verified PowerShell script that registers the Teams app, configures bot endpoints, sets up SSO with the correct redirect URIs, and validates the configuration.
- `office-addin/scripts/teams-bot/README.md` (57 lines): Documents the script's prerequisites and usage.
- Translations (de, en, es, fr, pl) for the setup flow UI strings in the Office add-in.

**Infrastructure:**
- `frontend/Dockerfile`, `.dockerignore`, `.gitattributes` updated to include the setup scripts in the Docker build context.
- `.github/workflows/docker-build.yml` updated to pass the script files through the build pipeline.

## Compatibility and configuration

No config changes. The PowerShell script is a deployment aid; existing Teams bot configurations continue to work unchanged.

## Evidence and review

- The PowerShell script uses Microsoft's official Azure CLI (`az`) and Teams API endpoints.
- All commands are idempotent (check before creating/updating).
- Error messages guide the admin to the correct fix.
- The script is a companion to the Teams bot integration and is referenced from the Teams setup documentation.
