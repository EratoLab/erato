## Summary

In a real two-turn Word test, gpt-5.2 had its structural plan rejected twice for the same reason: every heading carried styleRef (Heading1 on level 1, Heading2 on every level-2 heading) and every table carried styleRef: "TableNormal". The host rejects styleRef on both, so the model resubmitted the whole plan (35 KB of arguments, ~9K output tokens) each time.
