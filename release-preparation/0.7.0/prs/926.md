## Summary

Fixes ERMAIN-548. Live-reproduced on an EXO mailbox in Outlook on the web: Office.context.mailbox.ewsUrl/restUrl now report https://outlook.cloud.microsoft/... — Microsoft's unified cloud.microsoft domain rolling out to OWA. detectExchangeOnPrem()'s cloud-suffix allowlist didn't include it, so EXO mailboxes in OWA were classified as on-prem, which (a) triggered the 730 NAA veto — the add-in silently fell back to the oauth2-proxy path and EntraGraphTokenProvider never mounted — and (b) routed the mail data plane to EWS instead of Graph.
