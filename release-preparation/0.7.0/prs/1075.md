# PR #1075: Highlight selected item in SegmentControl

- Status: pending (diff reviewed)

## Summary

Fixes the selected-segment background color in the shared
`SegmentedControl.tsx` component: the active tab previously used
`bg-theme-bg-primary` (the page's primary background color), which could
make the selected segment visually indistinguishable from its container in
some themes, since both share the same "primary background" token. It now
uses the dedicated `bg-theme-bg-selected` token, consistent with how other
selected-state UI elsewhere in the app is styled. A new test asserts only
the active segment carries this class.

## Compatibility and configuration

None. Purely a one-line CSS class fix for a shared UI component; no
configuration, API, or migration changes. Affects any custom theme
relying on `--theme-bg-selected` being distinct from `--theme-bg-primary`
— if a theme defines them identically, this change has no visible effect.
