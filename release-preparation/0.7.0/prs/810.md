# PR #810: Show less details about assistants by default on new chat page

- PR: https://github.com/EratoLab/erato/pull/810
- Status: pending
- Category: Features and enhancements
- Theme: None

## Summary

Reworks `frontend/src/components/ui/Assistant/AssistantWelcomeScreen.tsx`
(the screen shown when starting a new chat with a specific assistant) to
hide the assistant's configuration details (system prompt preview, default
files list, "Edit Assistant Settings" button, and the missing-file-access
warning) behind a new modal (`ModalBase`), instead of always rendering
them inline in a persistent card below the assistant name/description.
The assistant's avatar circle now shows the assistant's initial letter
(`assistantInitial`, derived from `assistant.name`) instead of a generic
edit-pencil icon, and both the avatar and the assistant name are now
clickable buttons (`aria-label`/`title` "View assistant configuration")
that open the configuration modal. The modal content itself (system
prompt, files, edit button, inaccessible-files warning) is functionally
the same as what was previously always shown, just relocated into
`ModalBase` and made scrollable up to `max-h-48` (previously `max-h-32`
for the prompt preview).

## Compatibility and configuration

No configuration keys or migrations; purely a frontend UI change. No
functionality is removed — all previously-visible information (system
prompt, files, edit button) remains reachable, just via an extra click
(avatar or name) rather than shown by default.
