# PR #1296: Show Teams generation progress and separate the final answer

- PR: https://github.com/EratoLab/erato/pull/1296
- Status: pending (diff reviewed)
- Category: Features and enhancements
- Theme: Teams

## Summary

Substantially improves the Teams bot response experience by adding streaming progress indicators and separating intermediate updates from the final rendered answer.

**Progress infrastructure.** A new `host/progress.rs` module (106 lines) manages progress state for in-flight generations. The bot now sends progress updates as separate Teams cards (distinct from the final answer card), showing the user that the model is working. The progress card updates in place as the generation proceeds through distinct phases: "thinking...", "generating...", "reviewing...".

**Streaming rework.** `streaming.rs` (482 changes) is substantially rewritten to produce two output channels:

1. **Progress cards**: Incremental "still working" updates that are updated in real-time as the model generates tokens.
2. **Final answer card**: A complete, polished card that replaces the progress card when generation finishes.

The `handler.rs` (207 changes) and `host.rs` (346 changes) coordinate the progress-to-answer transition. The `connector.rs` (73 changes) is updated to support the new card update API.

**Background tasks.** `background_tasks.rs` (42 lines) adds a delivery-backstop that ensures progress updates are eventually delivered even if the initial Teams API acknowledgement times out.

**Separation logic.** The final answer is rendered separately from the progress stream, so the user sees a clean answer card rather than watching tokens appear incrementally. The `render.rs` module handles the final answer formatting.

**Tests.** A dedicated `streaming/tests.rs` module (406 lines) covers all streaming states: progress updates, answer delivery, error recovery, and timeouts.

## Compatibility and configuration

No config changes. The new progress UX is automatic for all Teams bot interactions.
