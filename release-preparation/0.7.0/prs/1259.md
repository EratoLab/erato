## Summary

In Word with "Include this document" on, several seconds passed between pressing send and seeing the message. The shared sendMessage inserts the optimistic message synchronously, but WordChatInput only called it after capturing the document (full .docx read in 64 KB slices plus three XML parses), fetching attached images one by one, and the budget check (a network call to /token usage/estimate that uploads the source three times).
