# PR #1315: Fix missing page title on delegated run pages

- PR: https://github.com/EratoLab/erato/pull/1315
- Status: pending
- Category: Bug fixes
- Theme: Delegation

## Summary

Fixes the browser tab title for a delegated run opened via a direct link
when that run has no row in the current sidebar listing (recent or
pinned) — previously the title silently stayed blank/stale because the
title logic only ever read `currentSession?.title`/`titleResolved` from
the sidebar's own listing data, which a delegated run that isn't in the
visible "recent" or "pinned" set never has. `ChatHistorySidebar.tsx` now
calls `useChatDetail` for the current chat id whenever it has no matching
listing row (via `skipToken` to skip the fetch entirely when a listing
row already supplies a title), and falls back to that fetched
`title_resolved` for the document title.

## Compatibility and configuration

None. Pure frontend bug fix; no new config, no API contract change
(reuses the existing `useChatDetail` generated hook). No migration.
