# PR #1065: Let deployments declare Office add-in launch events in config

- Status: pending
- Category: Features and enhancements

## Summary

The rendered Outlook manifest only substitutes branding scalars, so a deployment has no way to subscribe the add-in to a launch event (OnNewMessageCompose and friends). The capability exists in the Office manifest schema; we just had no way to express it.
