# PR #875: Replace e2e settle sleeps with observable waits; enforce via eslint

- PR: https://github.com/EratoLab/erato/pull/875
- Status: pending (diff reviewed)
- Category: Chores
- Theme: None

## Summary

E2E test-infrastructure-only change; confirmed by diff stat that no
backend/frontend/add-in product code is touched — only test spec files,
an eslint config, and CI workflow. Replaces several fixed-duration
`waitForTimeout` "settle sleeps" in the Playwright suite with observable
waits (polling an actual rendered condition instead of guessing a fixed
delay): a theme-transition screenshot check via `expect.poll`, a
button-visibility wait, and two debounced-search-result waits replacing
sleeps in Entra ID sharing tests. A handful of remaining sleeps are kept
but explicitly annotated as documented exceptions (bounded absence
windows, measurement windows, synthetic-event spacing) where the PR
argues converting them would weaken rather than strengthen the assertion.
A new ESLint rule (`playwright/no-wait-for-timeout`, as an error) is added
to the E2E test suite's lint config and wired into CI, with two specific
spec files config-ignored pending a separate CI-enablement decision.
