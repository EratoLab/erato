## Summary

No GitHub description beyond "Related Linear issue: ERMAIN-964"; evaluated
from the diff. Adds a config option controlling how an assistant's
description renders in the desktop Tools menu and mobile "add" menu (the
`@mention`/tool-selection dropdown). Confirmed via `config.rs`: a new
`AssistantToolsMenuDescriptionDisplay` enum (`none` / `truncated` (default)
/ `full`) is added as `assistants.tools_menu_description_display`.
`truncated` clamps the description to roughly two lines with an ellipsis
(per the doc comment), matching today's implicit behavior as the new
default; `none` hides it entirely and `full` shows it untruncated.

## Compatibility and configuration

New optional key, defaulting to today's effective behavior (no visible
change for existing deployments):

```toml
[assistants]
tools_menu_description_display = "truncated"  # default; or "none" / "full"
```

No migration.
