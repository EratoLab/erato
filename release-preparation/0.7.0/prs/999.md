# PR #999: Prepare frontend library for Git consumers

- PR: https://github.com/EratoLab/erato/pull/999
- Status: pending
- Category: Documentation
- Theme: Customer themes and component kits

## Summary

Makes the `@erato/frontend` library buildable when installed directly
from a Git URL/commit, rather than only from a pre-built package tarball.
Adds an npm `prepare` lifecycle script
(`"prepare": "pnpm build:lib:prepare"`) to `frontend/package.json` — npm/pnpm
automatically run a package's `prepare` script for Git-sourced
dependencies (since there's no publish/pack step to produce prebuilt
output), so a consumer pointing at this repo/commit via Git now gets the
library's `dist` output built automatically on install. The existing
`build:lib` script is refactored to reuse a new `build:lib:prepare` step
(everything except the final `pack-library.mjs` packing step) so both the
packed-tarball and Git-consumer paths share the same build logic.
Separately, all `@lingui/*` dependency versions in `frontend/package.json`
are pinned to exact versions (removing `^` semver ranges, e.g.
`"@lingui/cli": "^5.9.4"` → `"5.9.4"`) — likely to prevent a Git consumer's
own install from resolving a different (possibly incompatible) Lingui
minor/patch version than the one this repo was built and tested against.
`desktop-sidecar-protocol/.npmrc` adds `legacy-peer-deps=true` and its
`package.json` gets a 1-line change, presumably related to peer-dependency
resolution needed for the same Git-install scenario.

## Compatibility and configuration

No production runtime, configuration, or migration changes; this only
affects how `@erato/frontend` (and the desktop-sidecar-protocol package)
behave when installed as a dependency by an external consumer, either from
a packed release or directly via Git. Pinning `@lingui/*` versions could
in principle affect consumers who previously received Lingui patch updates
automatically via the `^` range — they'll now get exactly `5.9.4` until
this repo's pin is bumped, which is generally a compatibility-improving
change (avoids consumers depending on an untested Lingui version), not a
regression.
