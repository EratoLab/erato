# PR #855: Drop redundant recent-chats refetches on rename

## Summary

updateChatTitle already awaits invalidateQueries on the recent-chats key, which refetches every loaded page of the infinite query. Four call sites then refetched the same list again on top of that, so renaming a chat with N loaded pages issued 2N GETs of the expensive recent chats endpoint.
