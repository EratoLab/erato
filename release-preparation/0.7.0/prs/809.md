# PR #809: Remember collapsed state of recent chats in localStorage

- PR: https://github.com/EratoLab/erato/pull/809
- Status: pending
- Category: Features and enhancements
- Theme: None

## Summary

The "Recent" chat history section in the sidebar
(`frontend/src/components/ui/Chat/ChatHistorySidebar.tsx`) can be
collapsed/expanded via a header button; previously that expanded/collapsed
state was purely local component state (`useState`, reset to expanded on
every page load/remount). This PR converts `CollapsibleSection` to support
an optional controlled `expanded`/`onExpandedChange` pair (falling back to
its previous uncontrolled `useState` behavior when not provided, so other
call sites are unaffected), and wires the "Recent" section specifically to
a new `usePersistedState` hook backed by `localStorage`
(`frontend/src/hooks/usePersistedState.ts`) under the key
`erato.sidebar.recentChatsSectionExpanded`, defaulting to `true`
(expanded) when nothing is stored yet or the stored value isn't a boolean
(`parsePersistedBoolean`). The user's collapsed/expanded choice for the
Recent section now survives page reloads and new sessions in the same
browser.

## Compatibility and configuration

No configuration keys or migrations; purely client-side, per-browser
`localStorage` state. No server-side or cross-device persistence. Existing
users get the default (expanded) until they first toggle it.
