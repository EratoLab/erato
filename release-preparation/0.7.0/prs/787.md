## Summary

Bumps `@azure/msal-browser` from `^5.2.0` to `^5.15.0` and `@azure/msal-common`
from `^16.2.0` to `^16.10.0` in `office-addin/package.json`. The newer
`msal-browser` version changed the constructor signature of its
`InteractionRequiredAuthError` test double's real counterpart (it now takes
an `errorCode` as the first argument rather than just a message), which had
broken lint/type-checking; `office-addin/src/auth/__tests__/entraAuthSource.test.ts`
updates the mocked `InteractionRequiredAuthError` class and its call sites
(`new InteractionRequiredAuthError("interaction_required", "interaction
required")`) to match the new signature. `office-addin/pnpm-lock.yaml` is
updated accordingly.

## Compatibility and configuration

No configuration or migration changes. Purely a dependency version bump plus
a matching test-mock fix; no production auth logic in
`office-addin/src/auth/entraAuthSource.ts` itself is touched in this diff.
