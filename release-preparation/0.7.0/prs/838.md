# PR #838: Add PPTX file preview

- PR: https://github.com/EratoLab/erato/pull/838
- Status: pending
- Category: Features and enhancements
- Theme: File previews and formats

## Summary

Adds an in-app preview for PowerPoint files (`.ppt`/`.pptx`, matched by
extension or MIME type `application/vnd.ms-powerpoint` /
`application/vnd.openxmlformats-officedocument.presentationml.presentation`)
in the file preview modal, following the same pattern as the XLSX preview
added in #744. `FilePreviewContent` routes matching files to a new
`PptxPreview` component (`frontend/src/components/ui/FilePreview/PptxPreview.tsx`),
which renders the presentation via `ReactPptxViewer` from the new
`@extend-ai/react-pptx` dependency (`0.1.2`, WASM-based renderer,
`setWasmSource` pointed at the bundled `.wasm` asset). The viewer shows a
slide-mode view with a toolbar and thumbnail sidebar (`showToolbar`,
`showThumbnails`), and has loading, error ("Preview unavailable: this
presentation could not be loaded."), and empty ("Presentation preview is
empty.") states via new `filePreview.pptx*` i18n message IDs.

## Compatibility and configuration

No configuration keys or migrations; the preview is enabled
unconditionally for PPT/PPTX attachments, matching the existing DOCX/XLSX
previews. `frontend/pnpm-workspace.yaml` and
`office-addin/pnpm-workspace.yaml` presumably add
`@extend-ai/react-pptx@0.1.2` to `minimumReleaseAgeExclude` (1-line diff
each, consistent with the pattern from #744, not individually re-verified
here). `frontend/Dockerfile` and `frontend/vitest.config.ts` were touched
(4 and 1 lines respectively), likely to accommodate the new WASM
dependency's build/test assets — not independently verified line-by-line.
