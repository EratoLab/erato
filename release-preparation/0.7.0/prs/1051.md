# PR #1051: Promote attachment tile geometry to theme tokens

- PR: https://github.com/EratoLab/erato/pull/1051
- Status: pending (diff reviewed)
- Category: Bug fixes
- Theme: None

## Summary

Stacked on #1050. Moves the attachment tile's previously hard-coded
Tailwind dimension classes into new `--theme-layout-attachment-tile-*`
theme tokens, so a customer theme can retune them — following the same
wiring pattern as the existing `--theme-layout-chat-*` tokens (declared in
`theme.ts`'s type and defaults, `globals.css`'s CSS fallbacks, and
`ThemeProvider`'s override allowlist). Confirmed by reading the core
files in full:

- **Values genuinely unchanged, confirmed by direct comparison**: the
  removed Tailwind classes (`size-14` = 3.5rem, `size-28` = 7rem,
  `max-w-[15rem]`, `max-w-[18rem]`) match exactly the new token defaults
  in `theme.ts` (`compactMediaSize: "3.5rem"`, `mediumMediaSize: "7rem"`,
  `compactDocMaxWidth: "15rem"`, `mediumDocMaxWidth: "18rem"`) and
  `globals.css`'s CSS custom properties — confirming the PR's claim that
  only the values' *source* moved, not the values themselves.
- **New `stagedMaxHeight` token, confirmed via `theme.ts`/`globals.css`**:
  a fifth token, `--theme-layout-attachment-tile-staged-max-height`
  (default `12rem`), covers the staged area's scroll cap — per the PR
  description (not independently re-verified against
  `AttachmentTileList.tsx`'s specific usage) this is where the
  previously-hardcoded cap height now comes from.
- **Icon plate deliberately excluded, confirmed via `AttachmentTile.tsx`**:
  the `iconBox`/`icon` size classes (`size-8`/`size-4` compact,
  `size-10`/`size-5` medium) remain plain Tailwind classes, not tokenized
  — matching the PR's stated rationale that the icon plate is proportional
  chrome, not an independently meaningful dimension.

## Compatibility and configuration

None functionally — default rendering is byte-identical, confirmed by
the exact value match above. Adds new theme-customization surface: a
customer `theme.css` can now override attachment tile dimensions via the
five new `--theme-layout-attachment-tile-*` custom properties, where
previously these dimensions were fixed regardless of theme.
