# PR #912: Never let a progress observer break the observed request

## Summary

sidecar.progress.v1 polling documents that observation cannot affect the invoked request. In practice, an exception thrown by the caller's onProgress callback rejected the polling chain, and that rejection surfaced inside invoke's cleanup, replacing the request's real outcome with the observer's error.
