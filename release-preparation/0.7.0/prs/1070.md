# PR #1070: Add option to disable categories in Assistant Hub

- PR: https://github.com/EratoLab/erato/pull/1070
- Status: pending
- Category: Features and enhancements
- Theme: Assistant Hub and assistant sharing

## Summary

Adds `assistant_hub.enable_categories` (default `true`), letting an
operator turn off the categories feature in the Assistant Hub entirely.
When disabled, categories are no longer shown or selectable when
submitting/reviewing/browsing assistants — frontend pages
(`AssistantHubDetailPage.tsx`, `AssistantHubMyPage.tsx`,
`AssistantHubReviewPage.tsx`, `AssistantHubSubmitPage.tsx`,
`AssistantsPage.tsx`, `assistantHubUtils.tsx`) are all adjusted to
conditionally hide category-related UI. Backend
`assistant_hub.rs` gets a small (2-line) change, presumably surfacing the
new flag on the config-facing API response consumed by the frontend.

## Compatibility and configuration

New config key, defaulting to enabled (no behavior change for existing
deployments):
```toml
[assistant_hub]
enable_categories = true  # default
```
No migration. Deployments not using categories (e.g. a small
organization where category filtering adds no value) can now disable the
feature cleanly via configuration rather than it always being present.
