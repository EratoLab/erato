# PR #1118: Give every dropped file feedback and stage drops through a visible pipeline

- Status: pending

## Summary

Every dropped file now gets visible feedback, on the web and in the add-in: wrong-type and oversized rejections are named on all five upload surfaces, a mixed batch uploads its supported files and names only the unsupported ones, and dropped emails that could not be added say why. The Outlook add-in stages email drops through a visible pipeline (receiving → reading → resolving → staging) that starts the moment a drop lands, with .msg mailbox lookups resolved a few at a time and the renderer yielded before each step so the label keeps up.
