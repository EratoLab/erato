# PR #1141: Let the sidebar test's logo path reach the theme mock

## Summary

Trivial, fully verified test-only fix for a `main`-branch CI breakage
introduced by #1102 (this session's earlier review of #1102 confirmed
`useTheme().assetPaths.sidebarLogo` became the actual logo source,
replacing the old existence-probe mechanism). Confirmed via the diff: the
test file's `ThemeProvider` mock previously hardcoded `assetPaths:
{ assistantAvatar: null, sidebarLogo: null }`, so the "logo face carries
the badge" test — which set `mockedLogoPath` expecting it to drive the
rendered logo — found no logo rendered at all, since #1102 stopped
reading the logo from the now-retired existence-check path. The fix
wires `sidebarLogo: mockedLogoPath` into the mock, with every other test
in the file keeping its default (`mockedLogoPath` presumably unset/null
elsewhere) unaffected.
