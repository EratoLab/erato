# PR #1173: Let a message renderer consume host behaviour instead of copying it

## Summary

The ChatMessageRenderer extension point hands an override the whole message, so everything the host derives around it has to be re-derived kit-side. The openwebui kit's override had grown to 793 lines, of which only about 306 was its actual visual design — the rest was the host's own logic copied to reach the markup, and that copy had drifted.
