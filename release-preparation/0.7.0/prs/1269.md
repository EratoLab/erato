# PR #1269: Refresh apt index before installing sqitch in backend lint

## Summary

A one-line CI fix. The "Install sqitch" step in `docker-build.yml` ran
`sudo apt install -y sqitch` without refreshing the package index first,
so a stale index against the Azure Ubuntu mirror caused a 404 on a
transitive dependency (`libdbi-perl`), which made `lint (backend)` fail
with `sqitch: command not found`. Confirmed the fix directly and
exactly: the step now runs `sudo apt-get update && sudo apt-get install
-y sqitch` — matching the PR's described fix precisely, word for word.
Per the PR (not independently re-verified, and not relevant to this
repository's code): the disclosed second, separate, external failure
cause (e2e jobs failing because the OpenAI API key used in CI has run
out of credits) — explicitly described as "external, not fixed by this
PR."
