# PR #1309: Add configurable file context budgets and MCP previews with truncated content

- PR: https://github.com/EratoLab/erato/pull/1309
- Status: pending (diff reviewed)
- Category: Features and enhancements
- Theme: File previews and formats

## Summary

Introduces configurable per-file token budgets and MCP file previews with truncated content. This addresses the issue where large files consumed excessive context window space and where MCP file outputs were sent in full even when only a preview was needed.

Key changes:
- **Per-file token budgets**: Each file's token contribution to the context is capped at a configurable limit (`[file_context].max_tokens_per_file`). Files exceeding the budget are trimmed, with larger files sending only a representative preview portion.
- **MCP file previews**: Files destined for MCP servers can now be sent as previews (truncated content with size metadata) rather than full copies, controlled by the new `[mcp].preview.max_file_size` config.
- New `file_context` service managing token budget tracking and file content truncation
- Updated token estimation to account for truncated file content
- Config options for both file budgets and MCP preview limits
- Refactored file resolution, streaming, and embedded images services to work with the new budget-aware pipeline

This gives deployments control over context consumption, preventing context overflow from large file attachments while still providing useful content to the model and MCP servers.
