## Summary

Protocol 1.0 has no server-to-client push, so observing a long-running request while it runs becomes a poll pair: sidecar.progress.v1 { requestId } answers { state, trace } for a pending request. The trace is the same append-only step log a result may embed — clients apply steps by sequence (last one wins), so a log delivered in parts and a log delivered complete render identically.
