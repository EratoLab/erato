# PR #1188: Refuse a second write into a generating chat instead of taking it over (ERMAIN-776)

- PR: https://github.com/EratoLab/erato/pull/1188
- Status: pending
- Category: Features and enhancements
- Theme: Assistant delegation

## Summary

The generation lease was written as process state but read as chat state: start task replaced whatever was there, and the heartbeat re-asserted the holder from the in-memory map. That is survivable while a person is the only writer, and stops being survivable once a delegated task can deliver its own result into the conversation — "last start wins" then silently drops one of two legitimate writers.
