# PR #1258: Show Word apply progress on the Apply button and read documents less often

- Status: pending
- Category: Features and enhancements

## Summary

Applying a large Word plan felt broken: after the click the button did not react, then disappeared without a spinner, and the only status text sat below the review panel, often off-screen. The cause was that applyWordDocumentPlan parsed, validated, compiled and verified the plan synchronously before its first await, so the "applying" state could not paint, and the Apply button only rendered while the card was idle.
