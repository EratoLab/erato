## Summary

Teams hosts every tab in a sandboxed iframe , and since whatwg/html 6946 the spec forbids sandboxed frames from displaying PDFs via the native viewer. FilePreviewContent's PDF branch was a plain <iframe src={blobUrl} , so inside the Teams tab it could only ever render Chrome's grey "content is blocked" page.
