## Summary

CI-only follow-up to #870. Confirmed by reading the diff (3 lines in
`.github/workflows/docker-build.yml`): the `basic` E2E scenario now also
runs with 2 Playwright workers (following `many-models`'s change in
#870), and Playwright's trace recording switches from full-run (`--trace
on`) to `--trace on-first-retry` — recording DOM snapshots/screencast only
when a test actually needs to retry, reducing steady-state CPU load on the
CI runner while still preserving failure-diagnosis evidence for any test
that does fail and retry. No product code changes.
