## Summary

The grouped preview's file items (attachment, context) now use the shared tile, so the Outlook and Teams panes match the web composer. A group made only of those wraps into rows; selection rows, thread-message groups, loading placeholders and status notices stay a column, because a checkbox with a validation message under it is a different control from a tile and rows serve it better.
