## Summary

When the AI generates an erato-email-html draft and the user clicks Copy , navigator.clipboard.writeText(content) was called with the raw HTML string. Pasting into an email compose window showed literal markup (<p , <strong , …) on one line instead of formatted text (ERMAIN-417).
