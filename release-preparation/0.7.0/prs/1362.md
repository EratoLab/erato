# PR #1362: Keep comments that span several paragraphs intact when Word Replace rewrites a selection (ERMAIN-955) (#1362)

- PR: https://github.com/EratoLab/erato/pull/1362
- Status: pending
- Category: Bug fixes
- Theme: Word add-in

## Summary

A Word paragraph's underlying OOXML carries no mark for a comment whose
anchor spans *multiple* paragraphs, so when Erato's selection-rewrite (or
its own Undo) replaced a selection, such a comment's anchor could silently
move, shrink, or grow — the PR states this is a pre-existing defect in
shipped Word's own v2 Replace behavior, not something Erato introduced, and
fixes it for both. Per the PR body: the add-in now lists each paragraph's
comments before capturing/replacing a selection and refuses the rewrite (or
falls back to treating the data as stale) whenever a comment's anchor
extends outside the paragraph being touched, rather than silently
corrupting that comment's range. Confirmed via the diff stat: the fix is
concentrated in `wordSelectionTarget.ts` (320-line diff) and
`wordReplaceSelection.ts` (84-line diff), each with substantial new test
coverage (204-404 lines per file) exercising the paragraph-comment-boundary
detection directly.

## Compatibility and configuration
