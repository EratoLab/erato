## Summary

Component kits are separately built bundles, so any host module they import is evaluated a second time. For React we solved that with the ERATO REACT window bridge; for everything else kits carried stubs or copies — the source of the Beckhoff regressions (archive confirm dialog gone, feedback silently off, "..." loading indicator). 826 answered with a window-global bag; review feedback was to keep that surface minimal and make host modules importable instead.
