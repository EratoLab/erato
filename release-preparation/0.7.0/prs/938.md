# PR #938: Add support for rendering math equations in Markdown

- PR: https://github.com/EratoLab/erato/pull/938
- Status: pending
- Category: Features and enhancements
- Theme: File previews and formats

## Summary

Adds LaTeX math-equation rendering in chat messages via the standard
`remark-math` + `rehype-katex` (KaTeX) pipeline, added to the existing
`react-markdown` renderer in `frontend/src/components/ui/Message/MessageContent.tsx`
(`remarkPlugins={[remarkGfm, remarkMath]}`,
`rehypePlugins={[rehypeKatex]}`, plus the KaTeX CSS import). New
dependencies: `katex`, `rehype-katex`, `remark-math`. This is the standard
Markdown math syntax (`$...$` inline, `$$...$$` block, as supported by
`remark-math`) rendered to proper mathematical notation instead of raw
LaTeX text.

## Compatibility and configuration

No configuration keys or migrations; the feature is always active
(matching the pattern of the other Markdown-rendering enhancements this
cycle, e.g. #936 Mermaid), not gated by a flag. No breaking change —
messages without math syntax are unaffected; any message containing
`$...$`/`$$...$$` syntax that was previously shown as literal text will
now render as formatted math.
