## Summary

ChatMessageRenderer replaces the whole message, so an override silently drops whatever host chrome it did not think to rebuild. Two pieces were being lost: the MCP notices — a server or a tool switched off for the chat, or a server needing authentication — and the action-facet selection quote on a user message.
