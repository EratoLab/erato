# PR #935: Add numbering of pasted screenshots

- PR: https://github.com/EratoLab/erato/pull/935
- Status: pending
- Category: Bug fixes
- Theme: None

## Summary

Fixes pasted-screenshot filenames colliding in the chat composer. Browsers
commonly name clipboard-pasted images `image.png`/`image.jpg`; pasting
multiple screenshots in one chat previously gave them all the same
filename. A new utility,
`frontend/src/utils/file/disambiguatePastedImageFileNames.ts`, renames
each pasted `image.png`/`image.jpg` file to `image1.png`, `image2.png`,
etc., continuing the numbering sequence based on both already-attached
plain `image.<ext>` files and any already-numbered `imageN.<ext>` files
already present (tracked per extension independently, e.g. `.png` and
`.jpg` number separately), so repeated pastes across multiple paste events
in the same chat don't reset back to `image1`. `frontend/src/components/ui/Chat/ChatInput.tsx`
wires this into the paste-handling path (18-line diff).

## Compatibility and configuration

None. Purely a frontend UX fix for clipboard-pasted image naming; no
configuration, API, or migration changes.
