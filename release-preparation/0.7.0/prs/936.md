# PR #936: Add support for rendering Mermaid diagrams

- PR: https://github.com/EratoLab/erato/pull/936
- Status: pending (diff reviewed)
- Category: Features and enhancements
- Theme: File previews and formats

## Summary

Adds rendering of ```` ```mermaid ```` fenced code blocks in chat messages
as actual diagrams. A new `MermaidBlock.tsx` component lazily loads the
`mermaid` library (dynamic `import("mermaid")`, only when actually
rendering a Mermaid block, and only once the message is no longer
streaming — `showCode` defaults to `true` while `isStreaming`, showing raw
code during generation and switching to the rendered diagram once
complete) and renders it with `securityLevel: "strict"` and
`htmlLabels: false` (keeping labels as sanitized SVG text rather than
`foreignObject` HTML, since `DOMPurify` intentionally strips
`foreignObject`). The rendered SVG is additionally sanitized via
`DOMPurify.sanitize` with an SVG profile, explicitly forbidding `<script>`
and `<foreignObject>` tags and event-handler/`href` attributes
(`onerror`, `onload`, `onclick`, `onmouseover`, `onfocus`, `href`,
`xlink:href`) before being inserted into the page — a deliberate
defense-in-depth measure against a malicious/crafted Mermaid definition
(e.g. from an untrusted assistant response or shared chat) trying to
inject a clickable link or script into rendered output. A code/diagram
toggle button lets the user view the raw Mermaid source at any time; a
render failure falls back to showing the code with an error state rather
than crashing. `MessageContent.tsx` is updated to route mermaid-language
fences to this new component instead of plain syntax-highlighted code
(114-line diff).

## Compatibility and configuration

No configuration keys or migrations; the feature is always available
(not gated by a flag), consistent with the existing DOCX/XLSX/PPTX preview
pattern added earlier this cycle. New dependency `mermaid` added to
`frontend/package.json`. No breaking change — messages without mermaid
fences are unaffected, and existing mermaid-fenced text (if any assistant
happened to emit it before) now renders as a diagram instead of plain
code.
