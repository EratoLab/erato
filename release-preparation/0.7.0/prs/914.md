# PR #914: Extend mirroring of .po files to more directories

- PR: https://github.com/EratoLab/erato/pull/914
- Status: pending
- Category: Features and enhancements
- Theme: None

## Summary

Extends `discover_translation_po_sources`
(`backend/erato/src/frontend_environment.rs`), the function that finds
`.po` translation catalogs to mirror into the database (via the
`runtime_configuration` mechanism added in #897), to scan several
additional root directories it previously missed:
- The active custom theme's translations, for both the built path
  (`public/common/custom-theme/<theme>/locales`) and a "runtime theme"
  mount directly below the bundle root (`custom-theme/<theme>/locales`) —
  previously, a deployment's custom theme could ship its own `.po`
  overrides that were never mirrored.
- A legacy `locales` path directly under the web frontend bundle root, for
  older local/dev layouts.
- The Office add-in's own active-theme translations (in addition to its
  base `locales` directory, which appears to have already been scanned).

A catalog is still only mirrored if its compiled `.json` sibling exists
(matching the JIT-translation-serving path, unchanged from before), and
duplicates (by canonical path) across roots are still skipped. Extensive
new `tracing::debug!` logging was added throughout the discovery and
mirroring functions (`discover_translation_po_sources`,
`collect_translation_po_sources`,
`mirror_erato_backend_sources_with_translation_pos`) to make it possible
to diagnose which roots were scanned, what was found/skipped, and how many
rows were mirrored.

## Compatibility and configuration

No new configuration keys — this builds on the existing
`runtime_configuration.enabled` flag and `frontend.theme` setting (used to
determine which theme's directories to scan). No migration. For
deployments with `runtime_configuration.enabled = true` and a custom theme
configured, more `.po` files (the theme's own translation overrides) will
now be mirrored into the database than before — a broadening of what
#897 already introduced, not a new opt-in surface.
