# PR #1035: Access dynamic translation IDs without causing console warnings

- PR: https://github.com/EratoLab/erato/pull/1035
- Status: pending (diff reviewed)
- Category: Bug fixes
- Theme: None

## Summary

Fixes `useOptionalTranslation` (`frontend/src/hooks/i18n/useOptionalTranslation.ts`),
a hook used to look up dynamically-named, deployment-configured translation
IDs (e.g. `chat_models.<provider_id>.description`,
`assistant.<id>.tooltip`) that may or may not have an actual entry in the
locale catalog, returning `null` when absent so callers can conditionally
render. The previous implementation called Lingui's `t({ id, message: ""
})` with an empty fallback and then checked whether the result equaled the
ID itself or was empty. Per the new code's doc comment: "Lingui treats a
missing message with an empty fallback as the message ID, then warns in
production because that ID is an uncompiled string" — i.e. this pattern
itself triggered a Lingui console warning about an "uncompiled" message
whenever the dynamic ID had no catalog entry, which is exactly the
expected/normal case for most such optional translations.

The fix, `getOptionalTranslation`, first checks `translationId in
i18n.messages` directly against the loaded catalog before calling into
Lingui's translation resolution at all — if the ID isn't present, it
returns `null` immediately without ever triggering Lingui's warning path.
If present as a raw string, it's returned directly (also avoiding the
warning for a dynamically-loaded, not-yet-compiled catalog); otherwise it
falls through to `i18n._(translationId)`. Call sites
(`FacetSelector.tsx`, `ModelSelector.tsx`, `FeedbackCommentDialog.tsx`,
`useStarterPrompts.ts`) were simplified to use the new exported
`getOptionalTranslation` function directly where a hook wasn't otherwise
needed.

## Compatibility and configuration

None. Purely a frontend bug fix eliminating spurious console warnings;
the hook's external behavior (return `null` when no translation is
configured, otherwise the translated string) is unchanged for callers.
