# PR #1357: Preserve newline in JSON preview of e.g. tool calls (#1357)

## Summary

No GitHub description beyond "Related Linear issue: ERMAIN-959"; evaluated
from the diff. `JsonDisplay.tsx`'s string-value renderer (used for tool-call
argument/result previews, including the MCP approval card's JSON view) wraps
a string value in a plain `<span>` with no whitespace styling, so embedded
newlines collapsed and long values ran off without wrapping. The fix adds
Tailwind's `whitespace-pre-wrap break-words` to that span, so multi-line
string values (and long single-line values) now render with their original
line breaks and wrap within the available width instead of being collapsed
or overflowing.

## Compatibility and configuration
