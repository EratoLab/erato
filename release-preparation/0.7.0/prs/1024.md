## Summary

Trivial, fully verified one-line fix (ERMAIN-659): the assistant
create/edit form's save button previously only changed its text to
"Saving..." and disabled itself while a save was in flight, with no
animation. Confirmed via the diff: `loading={isSubmitting}` is added to
the submit `Button` in `AssistantForm.tsx`, alongside the pre-existing
`disabled={!isFormValid || isSubmitting || isContextExceeded}`. Since
`isSubmitting` is already wired to the React Query mutation's `isPending`
on both the create and edit pages (per the PR, not independently
re-verified — outside this file's diff), this single line adds a spinner
icon to both flows without any other change.
