# PR #1306: Show each Teams account as its own row in sidecar indexing settings

- PR: https://github.com/EratoLab/erato/pull/1306
- Status: pending (diff reviewed)
- Category: Features and enhancements
- Theme: Desktop Sidecar

## Summary

Updates the Sidecar indexing settings UI to display each Teams account as a separate row, matching the existing behaviour for Exchange/Outlook accounts. Previously, all Teams sources were grouped under a single entry, preventing per-account control over indexing.

**Changes:**

- **`IndexingSourceRow.tsx`**: New generic component for displaying a single source application's indexing status as a distinct row, with enable/disable toggle, status indicator, and action buttons.
- **`SidecarIndexingCard.tsx`** and **`SidecarIndexingCard.test.tsx`**: Updated to enumerate Teams sources per-account and render each as a separate `IndexingSourceRow`.
- **`indexingSources.ts`** library: Updated to correctly parse per-account Teams source descriptors from the Sidecar configuration, returning them as individual entries rather than a single aggregate.
- **Translations**: New locale strings for the per-account row labels (account name, status, controls) across all five locales.

## Compatibility and configuration

No config changes. Teams sources are automatically split into per-account rows based on the Sidecar protocol metadata introduced in #1305.

## Release note disposition

Include in the Desktop Sidecar section: Teams accounts now appear as separate rows in indexing settings.
