# PR #1021: Delegation surfaces: kit-aligned badges and chevrons, keyboard reveal, SPA origin link (ERMAIN-665)

- Status: pending (diff reviewed)
- Category: Bug fixes
- Theme: Delegation

## Summary

Audit follow-up on the two delegation surfaces added in #1013/#1009
(the runs list above the composer, and the delegated-run header): two
interaction-bug fixes plus alignment with new shared component-kit
primitives. Confirmed by reading the three most load-bearing diffs in
full:

- **The keyboard-reveal bug and its fix, confirmed via
  `DelegatedRunsSection.tsx`**: the `group/run` class previously lived on
  the inner `InteractiveContainer` div, while keyboard focus actually
  lands on the wrapping anchor — so `group-focus-visible` styling on the
  open-in-new-window hint never fired for keyboard users. Confirmed the
  fix moves `group/run` onto the anchor itself (the element with the
  `focus-ring-inset` class and the click handler), removing it from the
  inner container.
- **The full-page-reload bug and its fix, confirmed via
  `DelegatedRunHeader.tsx`**: the origin link previously was a bare `<a
  href>` with no click handler. Confirmed the fix adds an `onClick` that
  calls `e.preventDefault()` and `navigate(originHref)` (SPA routing via
  `useNavigate`), while explicitly passing through cmd/ctrl-click
  (`e.metaKey || e.ctrlKey`) unhandled so the browser's own new-tab
  behavior still works — matching the same escape hatch already used
  elsewhere for chat links.
- **`CountBadge` variant split, confirmed via the new
  `CountBadge.tsx`**: `attention` (action-primary-toned) vs. `count`
  (secondary-toned) are two distinct exported style constants, and the
  component defaults to `aria-hidden="true"`, confirmed overridable via
  `...props` spread (allowing a caller to pass `aria-hidden={false}`)
  for the documented add-menu opt-out case.
- Per the PR (not independently re-verified given the remaining scope):
  `DisclosureChevron` replaces the three hand-rolled rotate-chevron
  implementations (runs toggle, sidebar sections, settings entity rows —
  the latter's transition normalized from `transition-transform
  duration-200` to `theme-transition`); the settled-run dismiss button
  switches from `CheckIcon` to `CloseIcon` (confirmed directly in the
  `DelegatedRunsSection.tsx` diff read above, alongside a new `title`
  attribute duplicating the existing `aria-label`); the runs toggle
  button's `aria-label` states both the count and the most urgent status
  (confirmed directly: `toggleLabel` interpolates `runCount` and
  `chatAttentionStatusLabel` when an attention status exists) with
  `aria-controls` wired to a `useId()`-generated panel id (confirmed the
  panel div is now always rendered with that id, with only the row list
  itself gated on `isExpanded` — a correctness improvement over the prior
  version, which conditionally rendered the whole panel and would have
  left `aria-controls` pointing at a nonexistent element while
  collapsed); and the run header's parameter grid switches from a fixed
  `sm:w-32` label column to `grid-cols-[auto,1fr]` so long translated
  labels no longer clip (confirmed directly in the `DelegatedRunHeader.tsx`
  diff read above).
