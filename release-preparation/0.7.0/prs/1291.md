# PR #1291: Render indicator for tool budget approval as part of traces

- PR: https://github.com/EratoLab/erato/pull/1291
- Status: pending (diff reviewed)
- Category: Features and enhancements
- Theme: Traces and observability

## Summary

Adds a visual indicator in the frontend trace view when a tool call requires budget approval, helping users understand why generation pauses for approval and where time is spent.

**Changes in `Trace.tsx` (68 new lines):** The trace step rendering now checks whether each tool call has a pending or completed budget approval status. When a tool call is awaiting approval, a distinct badge/icon is shown on the trace step, and the step's duration bar accounts for the approval wait time.

**Changes in `types.ts` (36 changed lines):** The trace types are extended to carry budget approval state information: `pending_approval`, `approved`, `denied`, or `not_required`. Each trace step's metadata includes the approval status so the renderer can display it.

**Changes in `useThinkingGap.ts` (4 lines):** The thinking-gap logic (which shows "model is thinking..." pauses) now correctly accounts for budget approval pauses—approval wait time is not rendered as a thinking gap but as a distinct "awaiting approval" state.

**Translations:** New locale strings added for the approval indicator labels across all five supported locales.

**Tests:** `Trace.test.tsx` coverage expanded (101 new lines) including test cases for each approval state and the transition between states during streaming.

## Compatibility and configuration

No config changes. The indicator appears automatically in traces that involve tool budget approval; traces without approval are unaffected.
