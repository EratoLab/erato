## Summary

Adds an `<link rel="apple-touch-icon" sizes="192x192" ...>` tag to
`frontend/index.html`, pointing at
`/public/platform-office-addin/assets/color-icon-192x192.png` (the source
asset, `office-addin/public/assets/color-icon-192x192.png`, is mounted at
that public path by the existing static-file serving setup). This is the
icon shown when a user bookmarks/adds the app to their home screen on iOS
Safari (and similarly on some other platforms), which previously had no
dedicated icon and would fall back to a generic screenshot or the regular
favicon.
