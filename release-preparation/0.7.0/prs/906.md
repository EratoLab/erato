# PR #906: Unpublish de-reviewed assistants in assistants hub

- PR: https://github.com/EratoLab/erato/pull/906
- Status: pending
- Category: Bug fixes
- Theme: Assistant Hub and assistant sharing

## Summary

Fixes `review_version` in `backend/erato/src/models/assistant_hub.rs` so
that when a reviewer declines (does not accept) a previously-reviewed
Assistant Hub version, that version is also forcibly unpublished:
`is_published`, `is_current_published_version` are set to `false` and
`published_at` to `None`. Per the added code comment, "a declined version
must not remain visible as published if it was previously marked for
publication by another workflow" — i.e. a version could otherwise be
re-reviewed and declined after having already been published (and
possibly made current, per #790's publish-marks-current change), leaving
it wrongly still visible/current to audience viewers despite no longer
having review approval.

## Compatibility and configuration

No configuration keys or migrations. Behavior change: declining a
previously-published assistant version now also hides it from the
audience-facing hub, closing a gap where a declined version could remain
visible. No effect on versions that were never published or already
unpublished.
