# PR #1340: Show a sent selection while the answer streams, and say what "Ask again" does (ERMAIN-928)

- PR: https://github.com/EratoLab/erato/pull/1340
- Status: pending (diff reviewed)
- Category: Bug fixes
- Theme: Word selection editing

## Summary

Per the PR description: two fixes found during manual testing of the Word
selection editing feature introduced earlier in this batch. First,
confirmed directly in `handleUserMessageSaved.ts`: the optimistic →
server-confirmed message swap previously dropped `action_facet_id`/
`action_facet_args` from the server's `user_message_saved` event, so the
"Selection" quote under a just-sent message didn't appear until the
post-stream refetch instead of as soon as the server saved the message;
the handler now carries both fields through. This is shared frontend
code, so per the PR the fix also applies to Outlook, not only Word.
Second, the selection card's "Use current selection" button is renamed to
"Ask again with current selection" with new explanatory copy after the
click ("Your request is back in the message box. Select the passage you
mean, then send.") — per the PR, the old label overpromised that the
proposal would be applied to the current selection, when it actually only
repopulates the message box for a fresh model call on send.

## Compatibility and configuration

Pure bug fix / copy clarification; no config keys, no database migration,
