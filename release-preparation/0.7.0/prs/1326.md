# PR #1326: Add the selection foundations for Word selection editing (ERMAIN-928, wave A)

- PR: https://github.com/EratoLab/erato/pull/1326
- Status: pending
- Category: Features and enhancements
- Theme: Word selection editing

## Summary

Wave A of a multi-wave effort (ERMAIN-928) to let a user's selected text
in Word become part of the chat context and target of edits. Per the
PR's own description, **nothing is user-visible yet**: `word_selection`
is not advertised to the model and the composer is not wired to it. This
wave lays pure groundwork, confirmed by the diff being almost entirely
new, previously-unreferenced modules plus their own tests (38 files,
~9,950 insertions, 23 deletions): a host-neutral selection store
(`core/selection/`: snapshot store, dismissal state, conversation key,
and the `AddinSelectionChip` UI component), an abortable `Word.run`
wrapper (`wordRunGuard`) so nothing writes to the document after a
timeout, a selection-changed event broker
(`officeSelectionChangedBroker.ts`), a per-host platform helper
(`wordHostPlatform.ts`, reused by #1327's fix in this same batch), and a
large pure selection model (`wordSelectionAnchor.ts`,
`wordSelectionArgs.ts`, `wordSelectionFormatting.ts`,
`wordSelectionSupport.ts`) covering classification, per-host support,
refusal codes, and a reply parser. A new character-offset Word mock
(`selectionHost.ts`, ~4,000 lines, with Mac/PC/web/LTSC flavors) backs
all of it. The PR notes three deviations from the original plan, driven
by native-host probing: the formatting rule uses a measured "minimal"
mode, complex-script twins matching their Latin value count as benign,
and hazard detection adds object-model checks for hyperlinks, content
controls, and fields.

## Compatibility and configuration

None. Confirmed inert: a grep of this diff's non-test files for
`word_selection`/composer wiring finds nothing — every new file is a
standalone module or its own test, not yet called from any
user-reachable code path. No config keys, no migration, no behavior
change for any existing feature.
