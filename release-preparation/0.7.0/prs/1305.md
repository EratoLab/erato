# PR #1305: Add Teams account, sender email and edit time to the sidecar protocol

- PR: https://github.com/EratoLab/erato/pull/1305
- Status: pending (diff reviewed)
- Category: Features and enhancements
- Theme: Desktop Sidecar

## Summary

Extends the desktop Sidecar protocol with three new source metadata fields, improving the context available for search results and indexing status.

**New fields:**

| Field | Location | Purpose |
|---|---|---|
| `teams_account` | `source-descriptor.schema.json` | Identifies which Teams account the source belongs to, enabling per-account indexing status and source grouping. |
| `sender_email` | `search-query-v1-result.schema.json` | The email address of the message sender for email-type sources. Lets users see who sent a message directly in search results. |
| `edited_at` | `source-descriptor.schema.json` | The last modification time of the source, allowing freshness-based sorting and differential re-indexing. |

**Schema changes:** `desktop-sidecar-protocol` schemas updated for `source-descriptor` (31 lines) and `search-query-v1-result` (8 lines). Generated TypeScript types regenerated across all result types. Conformance test (`desktopSidecarProtocolExtensibility.test.ts`) extended to validate the new fields.

## Compatibility and configuration

No config changes. The protocol additions are backward-compatible; existing Sidecar clients ignore unknown fields.
