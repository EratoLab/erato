# PR #908: Order review queue by status, then oldest first

- PR: https://github.com/EratoLab/erato/pull/908
- Status: pending
- Category: Bug fixes
- Theme: Assistant Hub and assistant sharing

## Summary

Changes the ordering of `list_review_versions` (the reviewer queue for
Assistant Hub submissions,
`backend/erato/src/models/assistant_hub.rs`). Previously all versions
awaiting/having undergone review were sorted purely by `submitted_at`
descending (newest submission first), mixing pending and already-reviewed
items together. Now versions with status `STATUS_SUBMITTED` (still
awaiting review) are sorted first (sort key `0`), followed by all other
statuses (sort key `1`); within each group, versions are sorted by
`submitted_at` ascending (oldest first) via `review_status_sort_order`.
This means reviewers now see all not-yet-reviewed submissions first, in
first-submitted-first-served order, rather than a chronological mix of
pending and already-decided items.

## Compatibility and configuration

None. Purely a backend query/sort-order change to the reviewer-facing
listing endpoint; no schema, configuration, or API request/response shape
changes.
