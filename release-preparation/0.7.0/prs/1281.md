# PR #1281: Word review: building-blocks card for document plans

- PR: https://github.com/EratoLab/erato/pull/1281
- Status: pending (diff reviewed)
- Category: Features and enhancements
- Theme: Word add-in

## Summary

Introduces a rich card-based review UI for Word document plans, replacing the previous inline plan rendering. Users can now see proposed changes as structured cards showing what the model intends to modify, insert, or delete before approving or rejecting.

**New components:**

| Component | Purpose | Lines |
|---|---|---|
| `WordDocumentPlanReview.tsx` | Main review card for a complete document plan: title, diagnostics summary, per-change list | 437 |
| `WordHistoryCards.tsx` | Timeline of plan iterations (rejected → repaired → accepted), showing the history of the review session | 297 |
| `WordPlanChangeRow.tsx` | A single change within a plan, showing the affected element, the old/new content, and accept/reject actions | 610 |
| `WordProposalCard.tsx` | Card for displaying a model proposal (a complete rewrite of a section) with original/new side-by-side | 213 |
| `WordReviewCardParts.tsx` | Shared card sub-components (headers, footers, status badges, action buttons) | 322 |

**Integration.** The new review components are wired into the message content rendering pipeline:

- `ConversationMessages.tsx` and `MessageContent.tsx`: Updated to detect Word document plan tool calls and render the new card components instead of raw JSON.
- `MessageList.tsx` and `MessageList.test.tsx`: Updated to handle card-based review items in the message stream.
- `WordNativeBlockPreview.tsx` and `WordRichBlockPreview.tsx`: Extended to support the card-based layout with block-level styling.

**Testing.** `WordHistoryRendering.test.tsx` (453 lines) and `WordProposalCard.test.tsx` (149 lines) provide comprehensive coverage of the card rendering, including edge cases like empty plans, rejected plans, and repair proposals.

## Compatibility and configuration

No config changes. The new card UI replaces the previous inline plan display automatically—no migration or opt-in needed.

## Evidence and review

- Each new component follows the existing `WordReview` component conventions (same directory, same styling patterns).
- The plan change rows handle all three operations: add, replace, remove.
- History cards show the revision chain from initial proposal through rejections to the final accepted plan.
- Test coverage validates rendering of all card states.

## Release note disposition

Include in the Word add-in section of the release notes: document plan reviews now use a structured card layout for easier scanning and approval.
