# PR #1121: Reach the files inside forwarded emails

- PR: https://github.com/EratoLab/erato/pull/1121
- Status: pending
- Category: Features and enhancements
- Theme: Features and enhancements

## Summary

Forwarded emails (message/rfc822 parts) inside a dropped .eml or the open thread were opaque blobs: the add-in could name them but not look inside, so a large PDF buried in a forward went to the model whole or not at all. This PR parses forwards into nested attachment lists with path ids, renders them as nested cards with per-part checkboxes in the drop flow, and cuts dismissed inner parts out of the raw MIME bytes before the send (for drops and for the open thread).
