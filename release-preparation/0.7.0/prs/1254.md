## Summary

Follow-up to #1253 (the Teams bot backend/infrastructure reviewed
above): an admin-facing setup guide for the Azure-side configuration the
bot needs, surfaced on the existing add-in setup page plus a new
documentation page. Confirmed the core conditional-display logic and
step content directly:

- **The bot section renders only when the fetched manifest actually
  contains a bot, confirmed exactly, with no backend change**: the new
  `readTeamsBotSetup(manifest)` parses the already-fetched Teams
  manifest JSON client-side, returning `null` unless
  `manifest.bots[0].botId` is a non-empty string — `TeamsInstructions`
  only renders `<TeamsBotInstructions>` when this returns non-null.
  Matches "only when the rendered manifest contains a bot (read from the
  manifest the page already fetches, no backend change)" exactly —
  confirmed there's no new fetch or API call, just parsing of data the
  page already had.
- **Four steps matching the PR's own list exactly**: (1) a copyable
  messaging-endpoint field built from `TEAMS_BOT_MESSAGES_PATH =
  "/api/integrations/ms_teams/messages"` joined with the current origin
  — the identical endpoint path this session confirmed in #1253's
  `TeamsBotConfig` doc comment ("/api/integrations/ms_teams/messages");
  (2) "Under Channels, add Microsoft Teams"; (3) an OAuth-connection step
  explicitly stating "Its name must match `oauth_connection_name` in the
  Erato configuration" — matching "the OAuth connection (name must match
  `oauth_connection_name`)" exactly, the same config field this session
  confirmed exists in #1253's `TeamsBotConfig`; (4) a token-exchange-URL
  copy field rendered only `{bot.ssoResource ? (...) : null}`, where
  `ssoResource` is computed in `readTeamsBotSetup` as non-null only when
  the manifest's `webApplicationInfo.id === botId` (the manifest's SSO
  application is the bot itself) — matching "shown only when
  `webApplicationInfo` points at the bot, i.e. silent SSO is configured"
  exactly.
- **Links to the new guide, confirmed exactly**: `TEAMS_BOT_DOCS_URL =
  "https://erato.chat/docs/integrations/ms_teams"`, matching the new
  `site/content/docs/integrations/ms_teams.mdx` page added in this same
  PR.
- Per the PR (not independently re-verified given remaining scope): the
  full content of the new 121-line `ms_teams.mdx` documentation page
  (features, app registration, Azure Bot setup, OAuth connection scopes,
  the `msTeamsBot.directRoute` option, config example/option table, and
  limitations); the translation strings across de/es/fr/pl (36 lines
  each); and the 82-line new test additions in `AddinSetupPage.test.tsx`.
