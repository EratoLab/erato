## Summary

Batch of small UI polish fixes to the sidebar and search surfaces.
Confirmed the two most functionally meaningful items by full diff read:

- **"New Chat" icon default swap**: confirmed in `ChatHistorySidebar.tsx`
  the `fallbackIcon` for the New Chat row's `ResolvedIcon` changes from
  `EditIcon` to `PlusIcon` (matching the `useThemedIcon` default change in
  `useThemedIcon.ts`, 2-line diff, not independently re-verified but
  consistent) — a theme can still override this via its own `theme.json`
  icon-override channel, per the PR.
- **Sidebar history group collapse now animates and correctly defers
  unmounting**: confirmed via `Collapse.tsx` (exports a new
  `COLLAPSE_DURATION_MS = 300` constant matching the existing
  `duration-300` transition class, plus adds a previously-missing
  `motion-reduce:transition-none` guard) and `ChatHistorySidebar.tsx`'s
  `CollapsibleSection`: collapsed children are no longer unmounted
  immediately (which would snap the section closed with nothing to
  animate and, per the PR, could leave the infinite-scroll "load more"
  sentinel lingering inside a zero-height clipped box) — instead, a new
  `renderCollapsedChildren` state stays `true` through the 300ms
  transition (via a `setTimeout(..., COLLAPSE_DURATION_MS)`) before the
  children actually leave the DOM, correctly cleaned up on re-expansion
  or unmount via the effect's cleanup function.
- Per the PR (not independently re-verified in this review): Rename and
  Remove menu items in the two hand-duplicated chat-item context menus
  (`ChatHistoryList`, `SearchPage`) get pencil/trash icons respectively,
  with Remove additionally gaining `variant: "danger"` (turning its
  confirm-dialog button red, per the canonical `DropdownMenu` pattern);
  unused `LogOutIcon`/`MultiplePagesIcon` imports are pruned; the dev-only
  "Showing X of Y messages" readout and its two now-orphaned props are
  removed from `MessageListHeader`, with the corresponding 4 now-unused
  lingui message ids marked obsolete across all 5 locale files; and the
  search page's input is realigned onto the shared `Input` component
  (theme spacing/radius/border tokens, `type="search"`), with its search
  icon and clear button placed as flex siblings outside the field
  (following an existing Teams-picker precedent) specifically to avoid a
  padding-shorthand conflict the `Input` component has.

## Compatibility and configuration

None. Pure frontend visual polish; no configuration or API changes.
Visual/behavioral deltas: sidebar history sections now animate open/closed
instead of snapping instantly, the New Chat icon defaults to a plus
symbol, and several context-menu items gain icons/danger styling.
