# PR #951: Add a chat-input seam for grouped attachment previews

- PR: https://github.com/EratoLab/erato/pull/951
- Status: pending (diff reviewed)
- Category: Chores
- Theme: None

## Summary

Adds a new, currently-unused component-registry extension seam,
`componentRegistry.ChatAttachmentsPreview`, letting a future consumer
replace the composer's attachments region (currently always the flat
`FileAttachmentsPreview`) with a custom layout (e.g. grouped cards) while
still receiving the same props (file list, remove/preview callbacks) the
default gets. Confirmed by reading the diff: it defaults to `null`
(`emptyComponentRegistry`), is resolved via the existing
`resolveComponentOverride(override, FileAttachmentsPreview)` fallback
helper so nothing changes when unset, and is correctly gated to be
ignored whenever the pre-existing `ChatInputAttachmentPreview` override is
active (which already moves the preview inside the composer shell
entirely, making this separate region moot in that case). Per the PR,
this is a pure enabler — nothing in this diff actually registers a value
for the new seam.

## Compatibility and configuration

None. No behavior change for any current consumer, confirmed structurally
(defaults to `null`, falls back to the existing default component).
Component-kit-facing: a new registry key is available for a future
override to use.
