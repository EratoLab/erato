# PR #844: Reuse the shared Button for the add-menu trigger

- PR: https://github.com/EratoLab/erato/pull/844
- Status: pending (diff reviewed)
- Category: Bug fixes
- Theme: None

## Summary

Replaces the chat composer's "+" (add files/tools) menu trigger — a
hand-rolled `<button>` reimplementing the shared `Button` component's
`variant="icon-only"` styling with the same size (`size-9` ==
`btn-geometry-icon-sm`, 36px) and near-identical color/hover/disabled
tokens — with the actual shared `Button` component. Confirmed by reading
the diff: the hand-rolled version used a literal `rounded-md` (6px)
instead of the `--theme-radius-control` token, and carried none of
`Button`'s `data-*` theming hooks (from #843), meaning a custom theme
could not reach this specific control the way it could reach every other
icon button. Now `<Button variant="icon-only" size="sm">` is used, with
only `relative` remaining at the call site (to anchor the absolutely-
positioned unread-count badge, moved into `children`); the
`AnchoredPopover` trigger prop bag (ref, ARIA attributes, keyboard
handlers) spreads onto `Button` unchanged since it's a `forwardRef`
extending `ButtonHTMLAttributes`. New test coverage
(`ChatInputAddMenu.test.tsx`, 72 lines) is added for this component, which
previously had none — confirmed by the diff stat showing it as an
entirely new file.

Per the PR, this is independent of #843's new `geometry` prop, since
`variant="icon-only"` already implied icon geometry before that PR.

## Compatibility and configuration

None. Visual delta only, exactly as the PR states: the trigger's corner
radius changes from a hardcoded 6px to the themeable
`--theme-radius-control` token (8px under the default theme) — nothing
else changes in appearance or behavior.
