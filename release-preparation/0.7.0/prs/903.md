# PR #903: Add special share grant to share with whole organization

- PR: https://github.com/EratoLab/erato/pull/903
- Status: pending (diff reviewed)
- Category: Features and enhancements
- Theme: Assistant Hub and assistant sharing

## Summary

Adds a new sharing target: sharing an assistant with every logged-in user
in the organization, as a third option alongside the existing per-user and
per-organization-group sharing. Implemented as a synthetic share-grant
subject with fixed, sentinel values —
`subject_type = "organization"`, `subject_id_type = "organization_id"`,
`subject_id = "__organization__"` (constants defined in both
`backend/erato/src/models/share_grant.rs` and mirrored in
`frontend/src/types/sharing.ts`) — rather than a new database column or
schema change. `create_share_grant` validates that this combination is
used exactly (any other `subject_id` value with `subject_type =
"organization"` is rejected as invalid), and
`get_resources_shared_with_subject_and_groups` now also matches grants
with this sentinel target for any authenticated caller (no per-user
identifier needed, since it applies to everyone in the org).

Authorization is updated in `backend/policy/backend/backend.rego`
(`can_read_assistant`, and a new top-level `allow` rule) to recognize this
organization-wide grant and let any logged-in user (`subject_id !=
not_logged_in`) read an assistant shared this way. The frontend's
`SubjectSelector.tsx` (78-line diff) presumably offers "Whole
organization" as a selectable sharing target in the UI's subject picker,
alongside individual users/groups; `ShareGrantsList.tsx` and
`SharingDialog.tsx` display/handle it.

## Compatibility and configuration

No configuration keys or database migration — this reuses the existing
`share_grants` table's string columns with reserved sentinel values rather
than adding new columns or an enum variant. No breaking change; existing
grants (`"user"`/`"organization_group"`) are unaffected. New behavior is
purely additive (a new, previously-rejected combination is now accepted
and enforced).
