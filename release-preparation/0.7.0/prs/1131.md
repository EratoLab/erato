# PR #1131: Add an unarchive endpoint for chats (ERMAIN-794)

- Status: pending

## Summary

Adds POST /api/v1beta/chats/{chat id}/unarchive, a no-body endpoint registered beside the existing archive route. It clears archived at and writes nothing else: no cascade to delegated descendants, a 200 no-op on a chat that is not archived, and the same global policy engine.invalidate data() call archive already makes, so a shared view of a restored chat stops 404-ing immediately instead of after the 60-second snapshot.
