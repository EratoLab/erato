# PR #877: Run every e2e test in CI by default; port token-warning coverage

- PR: https://github.com/EratoLab/erato/pull/877
- Status: pending (diff reviewed)
- Category: Chores
- Theme: None

## Summary

E2E test-infrastructure-only change; confirmed by diff stat that no
backend/frontend/add-in product code is touched — only test spec files,
CI workflow, E2E README, eslint config, and an e2e-secrets setup script.
Flips the CI test-selection convention from opt-in (`@ci` tag required to
run) to opt-out (`@no-ci` tag required to skip), which the PR states had
been silently excluding 13 tests across 5 files under the old convention.
Roughly 13 previously-never-run tests newly enter CI (component-registry
override seam coverage, assistant facet enforcement, an untagged
"Assistant Management" block), two vacuous/dead test files are deleted
(`message-id-lifecycle.basic`, `audio-transcription.many-models`), and
token-warning coverage is ported from a `basic`-scenario spec to a new
`many-models`-scenario spec using a new `mock-llm-1k` mock model (context
size 1000) so token-threshold tests can self-calibrate their repeat counts
from the model's own reported token estimates rather than depending on a
specific tokenizer's exact character-to-token ratio.

## Compatibility and configuration

None for the shipped product. Purely CI/test-infrastructure scope; the
new `mock-llm-1k` mock model exists only in the E2E test scenario
generator, not in any product-facing configuration.

## Evidence and review
