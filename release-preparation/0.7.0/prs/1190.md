# PR #1190: Keep a delivered task result on the thread when a stale client replies (ERMAIN-778)

- PR: https://github.com/EratoLab/erato/pull/1190
- Status: pending
- Category: Features and enhancements
- Theme: Features and enhancements

## Summary

A delivered task result and the turn that reacted to it sit below the assistant row a client last saw. submit message deactivates the whole chat and reactivates only the anchor's ancestors, so a client that has not caught up would submit above them and silently branch both away. A recursive walk down the active thread past the server's own rows re-anchors the turn below them instead, and the existing reactivation then keeps them on the thread with no extra write.
