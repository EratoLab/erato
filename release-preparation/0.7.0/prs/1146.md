## Summary

- GET /me/mcp servers/{server id}/tools returns a server's tools with the effective projection: title (tool title → annotation title → name), normalized annotations plus an annotated flag (did the server send hints at all), approval: auto ask, user decision, is wait tool; title-sorted; status uses the existing McpServerStatusValue so an unconnected OAuth server is NEEDS AUTHENTICATION, not an error; 403 via rego, 404 when unconfigured.
