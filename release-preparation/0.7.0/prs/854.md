# PR #854: Pin a type scale per button size

- PR: https://github.com/EratoLab/erato/pull/854
- Status: pending (diff reviewed)
- Category: Bug fixes
- Theme: None

## Summary

Fixes the shared `Button` component's `CONTROL_SIZE_STYLES` only pinning
a font size for `size="sm"` (`text-sm`); `md` and `lg` set no font size at
all, so their text size came from whatever ambient container the button
happened to render in, rather than from the button's own `size` prop.
Confirmed by reading the diff: `md` now adds `text-base` (1rem) and `lg`
adds `text-lg` (1.125rem), completing the `sm`/`base`/`lg` scale. The PR
states this is not variant-driven (no color variant sets font size, only
the unrelated `list-item` variant for menu rows) and separately verified,
by walking the actual JSX ancestor chain (not proximity) of all 42
`md`/`lg` call sites, that none has an ancestor setting a text size — so
every one already inherits 1rem from `body`, making the `md` change a
behavior-preserving no-op that merely stops it being context-dependent.
The `lg` change is the one actual visible delta, affecting a single
production call site (the assistant hub's "Start chat" CTA), growing it
from an inherited 1rem to 1.125rem to follow the scale — the PR
explicitly notes this specific CTA's growth can be reverted to
`text-base` independently if undesired, without affecting the `md` fix.

## Compatibility and configuration

None. Pure frontend visual consistency fix; no configuration or API
changes. Visual delta: the single `size="lg"` button in the app ("Start
chat" CTA) grows from 1rem to 1.125rem text; every `size="md"` button is
unaffected in practice (already rendering at 1rem via inheritance).

## Evidence and review

Verified via this PR's squash-merge commit against its parent (both
present locally). Full diff read (2 files, 23 insertions/2 deletions) —
confirms the exact two-class addition described. The PR's claim about
walking all 42 `md`/`lg` call sites' JSX ancestry was not independently
re-verified (would require enumerating and inspecting all 42 sites), but
the claim is specific, falsifiable, and consistent with the change being
described as intentionally conservative (a no-op for `md`).
