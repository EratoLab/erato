# PR #744: Add XLSX file preview

- PR: https://github.com/EratoLab/erato/pull/744
- Status: pending (diff reviewed)
- Category: Features and enhancements
- Theme: File previews and formats

## Summary

Adds an in-app preview for `.xlsx` files (also matched by MIME type
`application/vnd.openxmlformats-officedocument.spreadsheetml.sheet`) in the
file preview modal, alongside the existing image/PDF/EML/DOCX previews.
`FilePreviewContent` now routes XLSX files to a new `XlsxPreview` component
(`frontend/src/components/ui/FilePreview/XlsxPreview.tsx`) that renders the
spreadsheet read-only via the `@extend-ai/react-xlsx` `XlsxViewer` component
(new dependency, version `0.15.0`, added to `frontend/package.json`). The
preview has its own light/dark theme toggle button (independent of the app
theme, defaulting to light) with loading, error ("Preview unavailable: this
spreadsheet could not be loaded.") and empty ("Spreadsheet preview is
empty.") states, all through new i18n message IDs under `filePreview.xlsx*`
in `frontend/src/locales/*/messages.po`. `showDefaultToolbar` is disabled and
`useWorker` is set to `false`.

## Compatibility and configuration

No configuration keys, flags, or migrations are introduced; the preview is
enabled unconditionally for XLSX attachments, matching how DOCX/EML previews
already work. `frontend/pnpm-workspace.yaml` and
`office-addin/pnpm-workspace.yaml` add `@extend-ai/react-xlsx@0.15.0` and its
transitive `@dukelib/sheets-wasm@0.1.21` to `minimumReleaseAgeExclude` so pnpm
does not block on the standard 5-day release-age delay for these new
packages. `component-kit-example/Dockerfile` and `frontend/Dockerfile` and
Vite/Vitest configs were touched, presumably to accommodate the new
dependency's build/worker assets — not independently verified line-by-line.
