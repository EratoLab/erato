# PR #1282: Fix Outlook and Teams indexing status and organize sidecar settings

- PR: https://github.com/EratoLab/erato/pull/1282
- Status: pending (diff reviewed)
- Category: Bug fixes
- Theme: Desktop Sidecar

## Summary

Fixes inconsistent indexing status reporting for Outlook and Teams sources in the desktop Sidecar protocol, and substantially reorganizes the Sidecar settings UI for clarity.

**Protocol fixes.** The desktop-sidecar-protocol schemas are updated so that indexing status results correctly reflect the state of Outlook and Teams sources:

- `sidecar-configuration.schema.json`: Extended with fields to represent per-application indexing configuration.
- `indexing-status-v1-result.schema.json`: Fixed to report status per source application (Outlook, Teams, etc.) rather than a single aggregate.
- `indexing-start-v1-result` and `indexing-stop-v1-result`: Updated to return per-application acknowledgement.
- `SPEC.md`: Updated protocol specification reflecting the corrected status model.
- Conformance fixtures (`source-indexing.json`) and conformance tests (`indexing-statistics.test.ts`) added to validate the new schema.

**Generated TypeScript:** All generated client types and validators regenerated.

**Frontend settings reorganization.**

- **`IndexingSourceRow.tsx`** (325 lines new): A new component that renders a single source application's indexing status as a distinct row with its own controls (enable/disable, reindex button, status indicator).
- **`SidecarIndexingCard.tsx`** (602 lines changed): Significant rework to display sources grouped by application, with per-source status and controls.
- **`SidecarMaintenance.tsx`** (92 lines new): New component for sidecar maintenance actions (clear cache, reset indexing).
- **`SettingsDisclosure.tsx`** (62 lines new): Reusable disclosure widget for collapsible settings sections.
- **`DesktopSidecarTabContent.tsx`**: Integrates the new indexing card and maintenance components.

**Library changes:**
- `indexingConfiguration.ts`: Rewritten to fetch, parse, and manage per-application indexing configuration.
- `indexingSources.ts`: New library for parsing source descriptors and grouping by application.
- `useSidecarIndexing.ts`: Updated to work with the new per-source status model.

**Translations:** All five locales updated for new UI strings.

## Compatibility and configuration

No config changes. The protocol changes are backward-compatible: the Sidecar client can continue using the old `indexing-status` response shape (the new fields are additive).

## Evidence and review

- Schema changes are additive (new fields added alongside existing ones).
- The conformance test validates that sample JSON matches the updated schema.
- Frontend tests for `SidecarIndexingCard`, `indexingConfiguration`, and `indexingSources` all pass.
- The `SettingsDisclosure` component is a general-purpose widget reusable outside the Sidecar settings.

## Release note disposition

Include in the Desktop Sidecar section of the release notes: indexing status is now reported per application (Outlook, Teams), and the settings panel is reorganized for clarity.
