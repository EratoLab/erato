# PR #1311: Pass the signed-in user to the desktop sidecar as its work account

- PR: https://github.com/EratoLab/erato/pull/1311
- Status: pending (diff reviewed)
- Category: Features and enhancements
- Theme: Desktop Sidecar

## Summary

Extends the desktop Sidecar configuration protocol to pass the signed-in Erato user's identity as the Sidecar's "work account," enabling the Sidecar to align its indexed sources and authenticated sessions with the correct user identity.

**Protocol changes.** The `sidecar-configure-v1-params` schema adds a `work_account` field carrying the user's email or identity string. The Sidecar can use this to:

1. Pre-fill the authenticated account context for source indexing (Outlook, Teams).
2. Disambiguate when multiple users are signed into the same desktop machine.
3. Route indexed sources to the correct user's indexing configuration.

**Schema updates:**
- `sidecar-configure-v1-params.schema.json` (22 lines): Adds `work_account` as an optional string field.
- `indexing-status-v1-result.schema.json` (22 lines): Includes the work account in status results.
- `source-descriptor.schema.json` (8 lines): Associates sources with the work account.
- Generated TypeScript types regenerated for all result types.
- Protocol `SPEC.md` updated with the new field documentation.

## Compatibility and configuration

No config changes. The field is optional; Sidecar clients that do not send it continue to work as before.
