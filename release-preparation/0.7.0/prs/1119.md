# PR #1119: Stage emails before send: eager resolution, per-part verdicts and a composer size gate

## Summary

Dropped and thread emails are now resolved into their final upload files as soon as they are staged, so the composer can show real sizes, per-part verdicts and a hard size/count gate before the user presses send. Every refused send (oversized part, failed trim, 413, unknown upload error) now takes one path: the draft is restored, nothing is sent, and the error is held next to the composer until the next attempt or until an offending drop is removed.
