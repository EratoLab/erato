# PR #1327: Select only the first paragraph for Show in Word on Word for the web (ERMAIN-932)

- PR: https://github.com/EratoLab/erato/pull/1327
- Status: pending
- Category: Bug fixes
- Theme: Word selection editing

## Summary

Fixes a Word-for-the-web-specific bug where "Show in Word" for a
multi-paragraph edit used `Range.expandTo(Range)` to select the whole
span, and native measurement showed this rewrites the formatting of the
first and last paragraphs in that range on the web host specifically. The
fix adds `selectsAcrossParagraphs()` (in `wordReviewLocation.ts`), which
checks `Office.context.diagnostics.platform` and only calls `expandTo`
across paragraphs on the two hosts confirmed safe (`"PC"`, `"Mac"`
desktop); every other platform (`OfficeOnline`, `iOS`, or no platform
info at all) now selects only the single first paragraph of the range
instead, both in `showWordReviewLocation` and `showWordParagraphs`. A new
`expansions()` counter on the mock Word document proves `expandTo` is
genuinely never called on the non-desktop paths.

## Compatibility and configuration

None breaking; purely a selection-behavior fix. No config keys. On
Word for the web/iOS, multi-paragraph "Show in Word" now selects a
narrower range (first paragraph only) than before — a deliberate
trade-off of completeness for correctness (no formatting corruption) on
hosts where the full-range selection was never safe.
