# PR #962: Add Markdown preview to assistant hub description edit field

- Status: pending

## Summary

Adds a new reusable `MarkdownPreviewInput` component
(`frontend/src/components/ui/Input/MarkdownPreviewInput.tsx`, new file,
232 lines) — a textarea with a tabbed "Markdown"/"Preview" toggle,
rendering the entered text via `react-markdown` + `remark-gfm` in the
preview tab, while the raw Markdown source remains the actual form value
at all times (per its doc comment, "switching tabs never changes the
value submitted by the containing form"). This is wired into the
Assistant Hub submission form
(`frontend/src/pages/AssistantHubSubmitPage.tsx`, 43-line diff) for the
assistant's (long) description field, and into `AssistantForm.tsx`
(27-line diff) — likely the same field on the regular assistant
create/edit form.

## Compatibility and configuration

None. Purely a frontend input-component addition; no configuration keys,
API changes, or migrations. The underlying stored value (Markdown text)
is unchanged — this only adds an optional live-preview UI for editing it.
