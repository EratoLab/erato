# PR #950: Name the viewer in Teams chat transcripts

- PR: https://github.com/EratoLab/erato/pull/950
- Status: pending (diff reviewed)
- Category: Bug fixes
- Theme: None

## Summary

Small enhancement to the Teams transcript feature: without knowing which
participant is the signed-in user, the model couldn't distinguish "you"
from "them" in an attached 1:1 or group chat transcript. Confirmed by
reading the diff: `parseTeamsChat`'s member-roster processing (renamed
`otherMemberNames` → `splitMemberNames`) now returns both the other
participants' names and the signed-in user's own display name (matched
against the roster the same way message senders already are, so it's
guaranteed to read identically to how the viewer's own messages are
attributed as sender). `buildTeamsTranscriptFile` then emits a one-line
"Viewer: {name} (the signed-in user)." legend at the top of a chat
section — confirmed correctly omitted for a channel section (channels
have no member roster to resolve a viewer identity from) and for a chat
whose roster never matched the signed-in user's identity, rather than
guessing or fabricating a value in either case.

None. Pure frontend enhancement; no configuration or API changes.
