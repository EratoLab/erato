# PR #947: Add pin/unpin icon; Add enforcement of pin limit

- PR: https://github.com/EratoLab/erato/pull/947
- Status: pending (diff reviewed)
- Category: Bug fixes
- Theme: None

## Summary

Two related UI fixes to the chat history "Pin" action
(`frontend/src/components/ui/Chat/ChatHistoryList.tsx`):
1. Adds dedicated `PinIcon`/`PinSlashIcon` icons to the pin/unpin menu
   item (previously text-only, no icon).
2. Enforces the existing pinned-chats limit in the UI: the menu item now
   disables itself and shows "Pin limit reached" instead of "Pin" once the
   number of currently pinned chats (`pinnedChatsCount`, threaded down from
   `ChatHistorySidebar`/`Chat.tsx`) reaches the configured limit
   (`pinnedChatsLimit`, sourced from the pre-existing
   `usePinnedChatsFeature().maxItems`, defaulting to `5` in the component
   props). Previously, per the diff, the pin action had no client-side
   limit check at all (`disabled: !canEdit` only) — a user could
   presumably attempt to pin more chats than the configured maximum
   allowed, relying only on the backend (if it enforces this) to reject
   or silently allow it.

## Compatibility and configuration

No new configuration keys — `pinnedChatsLimit`/`maxItems` is a pre-existing
feature setting (not introduced by this PR); this PR only makes the
frontend UI respect it before submitting a pin request, rather than only
after a possible rejection. No migration. Not verified whether the backend
independently enforces this same limit (this diff is frontend-only); if it
did not, this PR closes a real gap between the pin count shown as
promised and what was previously enforceable purely from the UI menu.
