# PR #1294: Fix Teams SSO resource generation and repair legacy OAuth connections

- PR: https://github.com/EratoLab/erato/pull/1294
- Status: pending (diff reviewed)
- Category: Bug fixes
- Theme: None

## Summary

Fixes issues with the Teams SSO resource generation in the PowerShell setup script and provides an automated repair path for legacy OAuth connections created with an older configuration schema.

**Setup script fixes.** The `Test-EratoTeamsSetup.ps1` script is updated (97 lines changed) with corrected Azure CLI commands for SSO resource registration. The previously generated resources used incorrect redirect URIs or missing scope declarations. The script now generates resources that match the Teams platform's current API expectations.

**Legacy OAuth repair.** When the script detects an existing OAuth connection created with the previous (incompatible) configuration, it offers to repair it by updating the redirect URIs and scopes without requiring a complete re-setup.

**Published setup script.** A versioned copy of the corrected script is published at `site/public/setup/teams/1.0.1/EratoTeamsSetup.ps1` (422 lines) alongside a release manifest, so deployments can point to a stable URL.

**Documentation.** The Teams integration docs (`ms_teams.mdx`) are updated with corrected SSO guidance reflecting the new resource generation commands.

## Compatibility and configuration

No config changes. The fix updates the external setup tooling; the Teams bot integration itself is unchanged.

Include in the Teams section of the release notes as a setup tooling fix.
