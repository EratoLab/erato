# PR #1308: Group sidecar indexing sources by application

- PR: https://github.com/EratoLab/erato/pull/1308
- Status: pending (diff reviewed)
- Category: Features and enhancements
- Theme: Desktop Sidecar

## Summary

Improves the Sidecar indexing settings UI by visually grouping sources by their source application (Outlook, Teams, etc.) rather than showing a flat list. This makes it easier for users to see which applications are contributing indexed data and to manage them (enable/disable all sources from a particular application, see per-application indexing status).

**Changes.**
- `SidecarIndexingCard.tsx`: Updated to render application-grouped source rows with application headers and per-application control toggles.
- `indexingSources.ts`: Updated to sort and group source descriptors by their application identifier.
- Test coverage updated for the grouped layout.
