# PR #808: Added compact variant of page headers

## Summary

Adds a `density` prop (`"default" | "compact"`, defaulting to `"default"`)
to the shared `PageHeader` component
(`frontend/src/components/ui/Container/PageHeader.tsx`). The `compact`
variant reduces vertical padding (`py-4` vs `py-8`) and the title/subtitle
bottom margins (`mb-3`/`mb-4` vs `mb-6`), making the header shorter. Three
pages opt into `density="compact"`: `AssistantHubPage.tsx`,
`AssistantsListPage.tsx`, and `SearchPage.tsx`. All other `PageHeader`
usages are unaffected (default density, no visual change) since the prop
defaults to `"default"`.

## Compatibility and configuration

No configuration keys or migrations; purely a frontend visual/layout
change, opt-in per page via the new prop, backward compatible with
existing `PageHeader` usages that don't pass `density`.
