# PR #832: Adjust local-auth dex to consistently use 127.0.0.1

- Theme: None

## Summary

Fixes an issuer-URL mismatch in the local development OIDC setup
(`frontend/local-auth/`, used for local/dev auth via Dex, not part of any
production deployment path). `dex-config.yml`'s `issuer` changes from
`http://0.0.0.0:5556` to `http://127.0.0.1:5556`, and
`oauth2-proxy.cfg`'s `oidc_issuer_url` changes from
`http://localhost:5556` to `http://127.0.0.1:5556` — both now consistently
use `127.0.0.1`, where previously they used three different hostnames
(`0.0.0.0`, `localhost`, and browser-visited URLs), which required
`insecure_oidc_skip_issuer_verification = true` to work around OIDC issuer
mismatches; that workaround flag is now removed from `oauth2-proxy.cfg`
since the issuer URLs are consistent. A corresponding E2E test
workaround in `e2e-tests/tests/chat-sharing.basic.spec.ts`, which
special-cased rewriting `0.0.0.0` URLs to `localhost` during login, is
removed as no longer necessary.

## Compatibility and configuration

Dev-tooling-only change; `frontend/local-auth/` is used for local
development authentication, not production deployments. No production
configuration keys, migrations, or runtime behavior affected. Improves
local OIDC issuer-URL consistency and removes an insecure verification
bypass from the local dev auth flow.
