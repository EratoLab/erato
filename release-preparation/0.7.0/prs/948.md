## Summary

Fixes the Teams conversation transcript file (from #939/#940) being
uploaded with MIME type `text/markdown`, which routed it through the
backend's markdown round-trip (parse → reserialize) before the model saw
it, rather than the verbatim-text extractor. Confirmed by reading the
diff: the `File` constructor's `type` changes from `text/markdown` to
`text/plain`, while the filename's `.md` extension is deliberately kept
unchanged — the code comment confirms this split is intentional: the
extension drives the UI's rich transcript preview, while the MIME type
determines which backend extractor handles the content, and `text/plain`
selects the one that hands the model the bytes as-is instead of
re-serializing them through a markdown parser (which could alter
formatting/whitespace the transcript relies on for readability).
