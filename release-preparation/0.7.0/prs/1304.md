# PR #1304: Play back recorded audio and show its transcript on sent messages (ERMAIN-903)

- PR: https://github.com/EratoLab/erato/pull/1304
- Status: pending (diff reviewed)
- Category: Features and enhancements
- Theme: Audio

## Summary

Adds audio playback and transcript display for sent messages containing recorded audio. Previously, after recording and sending an audio message, the sent message showed only the audio file attachment with no indication of what was said or a way to play it back directly.

**New components:**

| Component | Purpose |
|---|---|
| `AudioPreview.tsx` (138 lines) | A playable audio preview with waveform/progress visualization. Supports play/pause, scrub, and shows the current position. |
| `AudioTranscriptExcerpt.tsx` (78 lines) | Renders a compact transcript excerpt beneath the audio preview, showing the transcribed text from the speech-to-text service. |
| `ChatMessage.tsx` (125 changes) | Updated to detect audio message attachments and render the combined AudioPreview + TranscriptExcerpt component instead of a generic file tile. |
| `MessageAttachments.tsx` (48 changes) | Updated to include the audio preview in the attachment rendering pipeline. |

**Integration.** `FilePreviewContent.tsx` is updated to handle audio MIME types and route them to the new `AudioPreview` component. `AttachmentTileList.tsx` gets a small update for audio attachment display.

**Translations.** New locale strings for audio playback controls (play, pause, transcript label) across all five supported locales.

**Tests.** Coverage added for `ChatMessage` (73 lines), `MessageAttachments` (143 lines), and `AudioPreview` (64 lines) covering play/pause, transcript display, and edge cases like missing transcripts or corrupted audio.

## Compatibility and configuration

No config changes. Audio messages sent after this change automatically include playback and transcript display in the conversation history.
