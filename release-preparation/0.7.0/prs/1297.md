# PR #1297: Add Teams Stop, Retry, and edited-question regeneration

- PR: https://github.com/EratoLab/erato/pull/1297
- Status: pending (diff reviewed)
- Category: Features and enhancements
- Theme: Teams

## Summary

Adds interactive generation controls to the Teams bot: users can now stop an ongoing generation, retry a failed or unsatisfactory answer, and regenerate when they edit their question.

**New database entity.** `ms_teams_requests` (67 lines) tracks active generation requests with their state, the original user message, and the current generation status. This allows the bot to correlate control actions (stop, retry) with the correct in-flight generation.

**Controls module.** `controls.rs` (199 lines) implements the three actions:

| Action | Behaviour |
|---|---|
| **Stop** | Cancels the in-flight generation for the current user/conversation and sends a confirmation card. The streaming pipeline is terminated. |
| **Retry** | Re-dispatches the original user message for a fresh generation attempt. The previous (failed or unsatisfactory) answer is discarded. |
| **Regenerate** | When the user edits their question (Teams updates the original message), the bot detects the edit and regenerates the answer from scratch using the revised text. |

**Handler integration.** The activity handler (`handler.rs`, 503 changes) is updated to process interactive button callbacks from Teams cards (adaptive card actions). When a user clicks "Stop" or "Retry" on a bot message, the handler routes the action to the controls module. The `activity.rs` module (47 lines) maps Teams activity types to the control actions.

**Streaming integration.** The streaming pipeline (`connector.rs`, `host.rs`) is updated to support cancellation mid-generation, with proper cleanup of in-flight API calls.

**Tests.** `generation_tests.rs` (333 lines) covers all three control actions end-to-end, including edge cases like stopping an already-finished generation and retrying after a provider error.

## Compatibility and configuration

No config changes. The controls appear automatically on Teams bot messages.
