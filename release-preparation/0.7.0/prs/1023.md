## Summary

Opening a delegated run mid-generation left a ghost "New Chat" row in the sidebar. The cause: resumestream replays the chat's full event history, and the replayed chat created frame ran the same new-chat bookkeeping as a genuine first-turn submit — including seeding the pending sidebar placeholder.
