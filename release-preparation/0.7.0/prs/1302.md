## Summary

Reduces the final Erato binary link time in CI and local release builds, and includes a major refactoring of the message streaming module.

**Build time improvements:**

- **`Cargo.toml`**: Adds release profile flags `-C debug-info=0` and `-C split-debuginfo=off` to the native linker flags, reducing the amount of debug information the linker must process.
- **`Dockerfile`**: Updated to a multi-stage build that strips debug symbols from the final artifact while keeping the release binary's backtrace capability intact.
- **`check_release_backtraces.py`** (101 lines new): A CI script that verifies release binaries still produce usable function-name backtraces after symbol stripping, preventing debugging regressions.
- **`README.md`** (163 lines added): Expanded build optimization documentation covering the new build flags, the stripping process, and how to verify backtraces.

**Refactoring.** `message_streaming.rs` is substantially restructured (445 lines changed, 185 removed) — the large monolithic module is split into focused sub-modules for better maintainability. This is a code organisation change; no functionality is modified.

## Compatibility and configuration

No config changes. The build flags are internal; release binaries remain fully functional and debuggable.
