# PR #904: Collapse more than two assistant versions into "Show more"

- PR: https://github.com/EratoLab/erato/pull/904
- Status: pending (diff reviewed)
- Category: Features and enhancements
- Theme: Assistant Hub and assistant sharing

## Summary

On the "My Assistant Hub submissions" page
(`frontend/src/pages/AssistantHubMyPage.tsx`), when an assistant has more
than 2 submitted versions, only the most recent version is shown by
default, with a "Show more" button to reveal the rest (collapsed again via
a corresponding toggle). New helper `getVisibleAssistantHubVersions(versions,
isExpanded)`: returns just `versions.slice(0, 1)` when there are more than
2 versions and the group isn't expanded, otherwise returns the full list.
Per-assistant expand/collapse state is tracked in a `Set<string>` of
`hubAssistantId`s (`expandedGroups`), so each assistant group's
expand/collapse state is independent and resets on page reload (not
persisted). Assistants with 2 or fewer versions are always shown in full,
unaffected by this change.

## Compatibility and configuration

None. Purely a frontend display/UX change; no configuration keys, API
changes, or migrations. All version data is still fetched as before — only
the initial rendering of versions beyond the first is collapsed by
default.
