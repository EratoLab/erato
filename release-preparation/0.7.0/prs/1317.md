# PR #1317: Align with increased sidecar bootstrap slot size of 512KB

- PR: https://github.com/EratoLab/erato/pull/1317
- Status: pending
- Category: Chores & Developer experience
- Theme: Desktop Sidecar

## Summary

Raises the Windows executable bootstrap's embedded payload slot
(`EMBEDDED_BOOTSTRAP_SLOT_CAPACITY`) from a fixed 4096-byte array to a
heap-allocated 512 KiB (`512 * 1024`) buffer — matching a corresponding
increase on the sidecar's own installer side (not in this repo). The
previous 4070-byte usable payload capacity was tight enough that a long
`allowed_origins` list, a large TLS certificate chain, or an icon could
overflow it; `encode_executable_bootstrap_slot` now returns a `Vec<u8>`
instead of a fixed-size array, and the new usable payload capacity is
524262 bytes. Tests, `DISTRIBUTION.md`, and `configuration.mdx` are all
updated to the new numbers; the existing test that previously asserted a
100-origin allowlist *overflows* the slot now asserts it fits, with a new
12,000-origin case added to prove the (now much larger) limit is still
enforced and still produces an "embedded capacity" error.

## Compatibility and configuration

Backward compatible, capacity-only change: nothing that fit in the old
4070-byte limit becomes invalid, and the new limit only ever accepts
*more* data than before. No new config keys. Format version byte is
unchanged (still `1`), so the on-wire payload format itself is unchanged
— only how much of it the Windows executable transport can embed. No
migration.
