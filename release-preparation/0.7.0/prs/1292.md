# PR #1292: Update rust-genai fork to latest and incorporate fixes

- PR: https://github.com/EratoLab/erato/pull/1292
- Status: pending (diff reviewed)
- Category: Dependency changes
- Theme: None

## Summary

Updates the `rust-genai` crate (the backend's generative AI client library) to the latest upstream fork version. The key fix incorporated is the proper handling of Gemini tool call ID reuse—where Gemini reuses short call IDs like `"call_1"` across turns, the upstream library now generates unique IDs that don't collide.

**Dependency update:** `Cargo.toml` bumps the genai dependency version; `Cargo.lock` reflects the new crate tree (35 lines changed).

**Cleanup:** Removes the backend-side sign-in modules (`ms_teams_pending_sign_ins.rs`, `host/sign_in.rs`, `handler/sign_in_tests.rs`) and their wiring that were a temporary workaround for Teams bot sign-in. The sign-in flow has been reimplemented properly in #1293 using a different approach, so these files are superseded.

## Compatibility and configuration

No config changes. The dependency update is transparent to deployments.

## Evidence and review

- The genai fork version bump is visible in `Cargo.toml` and `Cargo.lock`.
- The removed sign-in modules are fully superseded by the new sign-in implementation in #1293.
- The Gemini tool call ID fix in the upstream library addresses the same issue that was partially worked around in #1284 at the backend level.
