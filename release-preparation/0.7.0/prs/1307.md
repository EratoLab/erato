# PR #1307: Add selfNote to sidecar search hits in the protocol

- PR: https://github.com/EratoLab/erato/pull/1307
- Status: pending (diff reviewed)
- Category: Features and enhancements
- Theme: Desktop Sidecar

## Summary

Adds a `selfNote` field to sidecar search hit results, exposing user-authored notes about documents from source applications that support them (such as OneNote pages, Outlook notes, or sticky notes).

**Protocol schema.** The `search-query-v1-result.schema.json` adds an optional `selfNote` string field to each search hit. When the source application provides a user-written note for a document, the Sidecar includes it in the search result. The generated TypeScript types are regenerated accordingly.

**Conformance test.** `desktopSidecarProtocolExtensibility.test.ts` extended to validate the new field in sample search results.

## Compatibility and configuration

No config changes. The field is optional and backward-compatible.
