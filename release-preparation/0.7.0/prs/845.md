# PR #845: Put the file-upload button on the shared Button and tokenise its styles

- PR: https://github.com/EratoLab/erato/pull/845
- Status: pending (diff reviewed)
- Category: Bug fixes
- Theme: None

## Summary

Replaces the idle-state file-upload button's hand-rolled implementation
(which tracked hover in React state purely to swap in a hardcoded
`bg-blue-100`/`text-blue-500`) with the shared `Button` component using
the new `geometry` prop from #843 (this PR is stacked on it, per the
description). Confirmed by reading the diff: `isHovered` state and both
mouse handlers are deleted entirely, replaced by `<Button variant="secondary"
geometry={iconOnly ? "icon" : "control"} size={iconOnly ? "sm" : "md"}>`,
relying on `secondary`'s own themed `hover:bg-theme-bg-hover` instead of a
literal blue. Two sibling hardcoded-blue spots are also tokenized: the
upload progress bar's `bg-blue-500` → `--theme-action-primary-bg`, and the
dropzone's active-state `border-blue-500 bg-blue-50 dark:bg-blue-900/20` →
`--theme-border-focus` + `--theme-bg-accent` (which resolves per-theme, so
the hardcoded `dark:` override is no longer needed). Per the PR, this
reflects a deliberate design-language point: the palette has a blue scale,
but `status.info` maps to neutral in this monochrome design language, so
the removed blues were unintentional outliers rather than a themed accent
color — not independently verifiable from this repo (a design-system
claim), but plausible given the tokens chosen as replacements are neutral/
accent tokens, not a blue-specific token.

`BUTTON_STYLES` in `fileUploadStyles.ts` (previously shared by this
button's idle/hover/loading/error/disabled states) is deleted entirely,
confirmed as dead code by the time of this PR: the `loading`/`error`/
`disabled` entries were already unused since `FileUploadStates` had
earlier migrated onto `Button` (per the PR), leaving only the
`default`/`hover`/`iconOnly`/`withLabel` entries this PR's own change
removes the last uses of. The generated shared component-registry barrel
correctly drops the now-nonexistent export in the same diff. New
`FileUploadButton.test.tsx` coverage is added (50 lines), confirmed as a
new file — the PR notes there were previously no tests for this component.

## Compatibility and configuration

None. Depends on #843's `geometry` prop (this PR cannot ship independently
of it). Visual delta under the default theme, as stated in the PR: the
icon-only form grows from 32x32 with `rounded-md` to 36x36 at
`--theme-radius-control`, matching the add-menu trigger (#844) and send
button beside it in the composer row; the labelled form's inline padding
shrinks from 16px to 12px.
